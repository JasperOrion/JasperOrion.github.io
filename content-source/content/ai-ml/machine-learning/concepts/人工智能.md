# 人工智能

## 定义

**人工智能**（Artificial Intelligence，简称 AI）是计算机科学的一个分支，旨在构造能够模拟、延伸和扩展人类智能的机器系统，使其具备**感知环境、进行推理、从经验中学习、做出决策**的能力。

## 核心要点

- AI 不是单一技术，而是一个**目标**——让机器表现出"智能行为"
- 传统 AI（符号主义）依赖人工编写的规则和逻辑推理；现代 AI（连接主义）依赖数据和统计学习
- AI 可大致分为三个层次：
  1. **弱人工智能（Narrow AI）**：在特定任务上达到或超越人类水平（当前所有 AI 系统均属此类）
  2. **强人工智能（General AI / AGI）**：具备与人类同等的通用认知能力（尚未实现）
  3. **超人工智能（Super AI）**：在所有领域全面超越人类（理论概念）

## 人工智能、机器学习、深度学习的关系

三者是**逐层包含**的同心圆关系：

```
┌─────────────────────────────────┐
│         人工智能 (AI)            │
│  ┌─────────────────────────┐    │
│  │    机器学习 (ML)         │    │
│  │  ┌───────────────┐      │    │
│  │  │ 深度学习 (DL)  │      │    │
│  │  └───────────────┘      │    │
│  └─────────────────────────┘    │
└─────────────────────────────────┘
```

- **人工智能**是最外层的大圆，涵盖一切让机器变"聪明"的技术，包括基于规则的专家系统、搜索算法、逻辑推理等
- **机器学习**是 AI 的一个子集，核心思想是**从数据中自动学习规律**，而非人工编写规则。它是当前实现 AI 的主流路径
- **深度学习**是 ML 的一个子集，使用**多层神经网络**从海量数据中自动提取层次化特征，尤其擅长处理图像、语音、文本等非结构化数据

> 简言之：深度学习 ∈ 机器学习 ∈ 人工智能。并非所有 AI 都是 ML，也并非所有 ML 都是 DL。
