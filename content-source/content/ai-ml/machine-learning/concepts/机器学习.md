# 机器学习

## 定义

**机器学习**（Machine Learning，简称 ML）是人工智能的核心子领域，其基本思想是：**不通过显式编程来规定机器的行为，而是让机器从数据中自动发现模式和规律**，并利用这些规律对新数据做出预测或决策。

## 与传统编程的对比

| | 传统编程 | 机器学习 |
|---|---|---|
| **输入** | 数据 + 规则 | 数据 + 答案（标签） |
| **输出** | 结果 | 规则（模型） |
| **特点** | 人工编写逻辑 | 自动学习规律 |

传统编程是人告诉机器"怎么做"；机器学习是给机器看大量例子，让机器自己总结出"怎么做"。

## 三大范式

### 监督学习（Supervised Learning）

训练数据带有**标注答案**（标签）。模型学习"输入 → 输出"的映射关系。

- **分类**：判断属于哪一类（垃圾邮件检测、图像识别）
- **回归**：预测连续数值（房价预测、股票趋势）
- 常见算法：线性回归、逻辑回归、决策树、随机森林、SVM、神经网络

### 无监督学习（Unsupervised Learning）

训练数据**没有标注**。模型自行发现数据中的隐藏结构。

- **聚类**：将相似数据自动分组（用户分群、文档归类）
- **降维**：压缩高维数据同时保留关键信息（PCA、t-SNE 可视化）
- 常见算法：K-Means、DBSCAN、PCA、自编码器

### 强化学习（Reinforcement Learning）

智能体通过**与环境交互**获得奖励或惩罚信号，目标是学习一个策略使得长期累积奖励最大化。

- 典型应用：游戏 AI（AlphaGo）、机器人控制、自动驾驶决策
- 核心概念：状态、动作、奖励、策略、Q 值

## 核心概念

- **特征（Feature）**：描述数据的属性，如"房屋面积""房间数量"
- **模型（Model）**：从数据中学到的数学函数
- **训练（Training）**：用数据调整模型参数的过程
- **泛化（Generalization）**：模型在未见过的数据上的表现能力
- **过拟合（Overfitting）**：模型对训练数据记忆过深，在新数据上表现差
