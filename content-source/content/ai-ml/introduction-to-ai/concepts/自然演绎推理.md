# 自然演绎推理

## 定义

**自然演绎推理**模拟人类"一步步推导"的思维方式——基于经典逻辑规则，从已知真事实**直接**推导新结论。最直观、最自然，但容易组合爆炸。

## 核心推理规则

与[一阶谓词逻辑](/articles/ai-ml/introduction-to-ai/concepts/一阶谓词逻辑/)共享同一套逻辑基础：

| 规则 | 全称 | 含义 |
|------|------|------|
| **P 规则** | Premise 前提引入 | 任何时刻可引入给定前提 |
| **T 规则** | Tautology 永真式引用 | 由已证的公式推导新公式 |
| **CP 规则** | Conditional Proof | 要证 P→Q，假设 P 成立，推出 Q 即完成 |
| **假言推理** | Modus Ponens | `P→Q, P ⊢ Q` |
| **拒取式** | Modus Tollens | `P→Q, ¬Q ⊢ ¬P` |
| **假言三段论** | Hypothetical Syllogism | `P→Q, Q→R ⊢ P→R` |
| **反证法** | Proof by Contradiction | 假设 ¬Q，推出矛盾，则 Q 成立 |

## ⚠️ 两类常见谬误

| 谬误 | 形式 | 反例 |
|------|------|------|
| **否定前件** ❌ | `P→Q, ¬P ⊢ ¬Q` | 没下雨 ≠ 地不湿（洒水车） |
| **肯定后件** ❌ | `P→Q, Q ⊢ P` | 地湿了 ≠ 下雨了（洒水车） |

> [!important] **蕴含式只能顺着箭头方向推**：P→Q 只能由 P 推 Q，或由 ¬Q 推 ¬P。

## 经典例子：小王喜欢 ds 课程

```
已知:
  F1: ∀x (EasyCourse(x) → Like(Wang, x))     "小王喜欢所有容易的课程"
  F2: CS_Course(ds)                            "ds 是 C 班的课程"
  F3: ∀x (CS_Course(x) → EasyCourse(x))       "所有 C 班课程都是容易的"

证明: Like(Wang, ds)

推理:
  1. CS_Course(ds)                             P 规则（F2）
  2. CS_Course(ds) → EasyCourse(ds)            F3 全称实例化
  3. EasyCourse(ds)                            1、2 假言推理
  4. EasyCourse(ds) → Like(Wang, ds)           F1 全称实例化
  5. Like(Wang, ds)                            3、4 假言推理 ✓
```

## 优缺点

| ✅ 优点 | ❌ 缺点 |
|----------|----------|
| 过程自然易懂 | **组合爆炸**：中间结论指数级增长 |
| 规则丰富（P/T/假言/拒取/三段论） | 缺乏策略控制，盲目推导 |
| 可嵌入领域启发知识 | 不适合大规模知识库 |
