# 神经网络训练

## 定义

**神经网络训练**是指通过数据不断调整网络中的**权重（weights）和偏置（biases）**，使网络输出尽可能接近真实目标的过程。通俗地说，训练就是让网络"从错误中学习"。

## 核心流程：三步循环

一次完整的训练迭代可以概括为三个步骤：

```
前向传播 → 计算损失 → 反向传播（更新参数）→ 回到前向传播 → ...
```

### 第一步：前向传播（Forward Propagation）

将输入数据逐层向前传递，每一层经过线性变换（加权求和）+ 非线性激活，最终在输出层得到预测值。

想象水流从输入层流入，经过各隐藏层的加工，在输出层流出——这就是"前向"的含义。

### 第二步：计算损失（Loss Computation）

将预测值与真实值比较，用一个**损失函数**（Loss Function）量化差距的大小：

| 损失函数 | 适用场景 | 含义 |
|---------|---------|------|
| 均方误差（MSE） | 回归问题 | 预测值与真实值之差的平方的平均 |
| 交叉熵（Cross-Entropy） | 分类问题 | 衡量预测概率分布与真实分布的差距 |

损失越大，说明模型"错得越离谱"；训练的目标就是**最小化损失**。

### 第三步：反向传播 + 梯度下降（Backpropagation + Gradient Descent）

这是神经网络训练的核心机制，也是最精妙的部分：

1. **反向传播**：从输出层开始，利用链式法则逐层计算**损失对每个参数的偏导数（梯度）**。梯度告诉我们：调整这个参数时，损失会朝哪个方向变化、变化多快
2. **梯度下降**：沿着梯度的**反方向**更新参数（让损失减小）：
   ```
   w_new = w_old - 学习率 × 梯度
   ```
3. 重复整个过程，损失逐步下降，模型表现逐步提升

> 直观类比：你站在山上，目标是走到山谷最低点。你环顾四周找最陡的下坡方向（梯度），跨出一小步（学习率控制步长），然后再次观察——重复直到到达谷底。

## 关键概念

### 学习率（Learning Rate）

控制参数更新的步长。太大可能跳过最优点甚至发散，太小则收敛缓慢。是训练中最重要也最难调的**超参数**之一。

### Epoch、Batch、Iteration

- **Batch（批次）**：每次一次前向+反向传播所用的样本数。全部数据太大，通常分成小批处理
- **Epoch（轮次）**：全部训练数据完整过一遍
- **Iteration**：一次参数更新（一个 batch 完成一次前向+反向）

### 过拟合与正则化

模型在训练数据上表现优异但在新数据上表现差，称为过拟合。常用对策：
- **早停（Early Stopping）**：验证集表现不再提升时停止训练
- **Dropout**：训练时随机"关掉"一部分神经元，防止共适应
- **权重衰减（Weight Decay）**：限制参数不要过大

## 训练框架

现代深度学习训练通常依赖 GPU 加速，主流框架包括 PyTorch（学术界首选）、TensorFlow / Keras（工业界广泛使用）、JAX（新兴高性能框架）。
