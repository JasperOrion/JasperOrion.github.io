# 深度学习

## 定义

**深度学习**（Deep Learning，简称 DL）是机器学习的一个分支，其核心特征是使用**多层人工神经网络**对数据进行**层次化的特征提取**与**表示学习**（Representation Learning）。"深度"一词指的就是网络的层数众多。

## 核心思想：层次化表示

深度学习的精髓在于**逐层抽象**。以图像识别为例：

```
输入像素 → 第一层检测边缘 → 第二层组合成形状 → 第三层识别部件 → 高层识别完整物体
```

浅层网络学到的只是低级特征（边缘、颜色），深层网络能学到越来越**高级、语义化**的特征，这正是"深度"带来的能力跃迁。

## 与机器学习的区别

| 维度 | 传统机器学习 | 深度学习 |
|------|------------|---------|
| **特征工程** | 需要人工设计和提取特征 | 自动学习层次化特征（端到端） |
| **数据需求** | 适量数据即可工作 | 依赖大规模数据才能发挥优势 |
| **计算资源** | CPU 即可 | 通常需要 GPU/TPU 加速 |
| **可解释性** | 相对较好（决策树、线性模型） | 较差（"黑箱"问题） |
| **代表算法** | SVM、随机森林、XGBoost | CNN、RNN、Transformer、GAN |

## 为什么深度学习近年爆发？

三个关键因素的汇聚：

1. **大数据**：互联网时代产生了前所未有的海量标注数据
2. **算力提升**：GPU 并行计算使大规模矩阵运算成为可能
3. **算法突破**：ReLU 激活函数、Batch Normalization、残差连接（ResNet）、自注意力机制（Transformer）等关键创新解决了深层网络的训练难题

## 主要网络架构

| 架构 | 擅长领域 | 代表模型 |
|------|---------|---------|
| CNN（卷积神经网络） | 图像识别、目标检测 | ResNet、YOLO |
| RNN / LSTM | 序列数据、时间序列 | LSTM、GRU |
| Transformer | 自然语言处理、多模态 | BERT、GPT、ViT |
| GAN（生成对抗网络） | 图像生成、风格迁移 | StyleGAN |
| 扩散模型 | 高质量图像生成 | Stable Diffusion、DALL·E |
