# P1498 南蛮图腾

## 题目

> 给定正整数 $n$，输出大小为 $n$ 的南蛮图腾（分形图案）。
>
> - 输入：一个正整数 $n$（$n \le 10$）
> - 输出：图腾的字符画

### 输入输出样例

输入：
```
2
```
输出：
```
   /\
  /__\
 /\  /\
/__\/__\
```

输入：
```
3
```
输出：
```
       /\
      /__\
     /\  /\
    /__\/__\
   /\      /\
  /__\    /__\
 /\  /\  /\  /\
/__\/__\/__\/__\
```

---

## 思路

### 为什么分形打印不能直接递归 cout

普通递归题（斐波那契、二分查找等）可以边递归边输出，因为**每层输出独立成行或独立成段**。

但分形题不行——以 n=2 为例，第三行 ` /\  /\ ` 同时包含了**左下 n=1 的第一行**和**右下 n=1 的第一行**。一行之内的字符可能来自多个递归分支。

> **核心矛盾**：`cout` 是流式的，打出去就不能回头改。但分形的每一行由多个子图案共同拼接而成。

**解决方案**：先分配一个二维字符数组作为"画布"，递归填充画布，最后一次性逐行打印。

### 递归结构

基本单元（n=1），高 2 行、宽 4 列：

```
 /\
/__\
```

对于 $k \ge 2$，第 $k$ 级图案由 3 个第 $k-1$ 级图案拼接而成：

| 位置 | 行偏移 | 列偏移 | 含义 |
|------|--------|--------|------|
| **顶部**（居中） | $0$ | $2^{k-1}$ | 唯一的顶部副本，右移半高 |
| **左下** | $2^{k-1}$ | $0$ | 左下半区 |
| **右下** | $2^{k-1}$ | $2^{k}$ | 右下半区，右移子图案完整宽度 |

**关键参数**：第 $k$ 级子图案的高度 $h_k = 2^k$，宽度 $w_k = 2^{k+1}$（宽度永远是高度的 2 倍）。

以 n=2 为例标注三个 n=1 在画布上的位置：

```
            列→
        0   1   2   3   4   5   6   7
    0   ·   ·   ·   /   \   ·   ·   ·    ← 顶部 n=1 从 (0, 2) 开始
    1   ·   ·   /   _   _   \   ·   ·
    2   ·   /   \   ·   ·   /   \   ·    ← 左下从 (2, 0)，右下从 (2, 4)
    3   /   _   _   \   /   _   _   \
        └──左下 n=1──┘   └──右下 n=1──┘
```

### 分形题通用框架

```
1. 确定基本单元（n=1 长什么样）
2. 找出递归拼接规律（n 级 = 几个 (n-1) 级 + 每个的偏移量）
3. 计算总尺寸，分配画布，初始化为空格
4. 递归填充画布
5. 逐行打印画布
```

## 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<vector<char>> grid;

// 在画布的 (x, y) 位置绘制第 n 级图腾
void draw(int n, int x, int y) {
    if (n == 1) {
        // 基本单元（2 行 × 4 列）
        //    /\
        //   /__\
        grid[x][y + 1] = '/';
        grid[x][y + 2] = '\\';
        grid[x + 1][y] = '/';
        grid[x + 1][y + 1] = '_';
        grid[x + 1][y + 2] = '_';
        grid[x + 1][y + 3] = '\\';
        return;
    }
    int h = 1 << (n - 1);   // 子图案高度 = 2^(n-1)
    int w = 1 << n;          // 子图案宽度 = 2^n

    draw(n - 1, x, y + h);        // 顶部：右移 h 列（注意 h = w/2）
    draw(n - 1, x + h, y);        // 左下：下移 h 行
    draw(n - 1, x + h, y + w);    // 右下：下移 h 行，右移 w 列
}

int main() {
    int n;
    cin >> n;

    int H = 1 << n;        // 总高度 = 2^n
    int W = 1 << (n + 1);  // 总宽度 = 2^(n+1) = 2 × 高度

    // 用空格填满整个画布
    grid.assign(H, vector<char>(W, ' '));

    draw(n, 0, 0);

    // 逐行输出
    for (int i = 0; i < H; i++) {
        for (int j = 0; j < W; j++)
            cout << grid[i][j];
        cout << '\n';
    }
    return 0;
}
```

| 项目 | 值 |
|------|-----|
| 时间 | $O(4^n)$——每个格子恰好被填充一次 |
| 空间 | $O(4^n)$——画布数组大小 $2^n \times 2^{n+1}$ |
| 递归深度 | $O(n)$，$n \le 10$ 完全安全 |

### 递归轨迹（n=2）

```
draw(2, 0, 0)
  h=2, w=4
  ├── draw(1, 0, 2)     → 在 (0,2) 画基本单元（顶部）
  ├── draw(1, 2, 0)     → 在 (2,0) 画基本单元（左下）
  └── draw(1, 2, 4)     → 在 (2,4) 画基本单元（右下）
```

## 常见错误

### 1. 试图边递归边 cout（❌ 最根本的错误）

```cpp
// ✗ 做不到——打印后无法"回头"在同一行插入字符
void draw(int n) {
    if (n == 1) { cout << " /\\\n/__\\\n"; return; }
    draw(n - 1);  // 子图案已经打印完毕，没机会再往它们中间插东西
}
```

必须用**画布数组**，全部填充完再统一输出。

### 2. 右下角的列偏移写成了 h 而不是 w

```cpp
// ✗ 错误：右下角用了 h（子图案高度）做列偏移
draw(n - 1, x + h, y + h);
// ✓ 正确：用 w（子图案宽度 = 2h）
draw(n - 1, x + h, y + w);
```

**为什么**：每个子图案宽是高两倍（`/\` 和 `/__\` 的关系）。右下角必须跳过左下角子图案的**完整宽度**，而不是只用高度。

### 3. 总宽度算错

```cpp
// ✗ 错误：宽高一样
int H = 1 << n, W = 1 << n;
// ✓ 正确：宽度是高度的 2 倍
int H = 1 << n, W = 1 << (n + 1);
```

### 4. 画布没有初始化为空格

```cpp
// ✗ 未初始化 → 未填充的格子是随机字符
vector<vector<char>> grid(H, vector<char>(W));
// ✓ 用空格填满
grid.assign(H, vector<char>(W, ' '));
```

## 总结

1. **分形打印核心思维**：画布数组 + 递归填充 + 最后一次性输出，丢掉"边递归边 cout"的习惯
2. **三路递归**：顶部（右移 $h$）+ 左下（下移 $h$）+ 右下（下移 $h$、右移 $w$）
3. **尺寸关系**：第 k 级高 $2^k$、宽 $2^{k+1}$，宽永远是高的 2 倍
4. **右下角用 w 不是 h**：最容易写错的地方，写完务必用 n=2 手算验证
5. **递归深度**：$n \le 10$ 时最深 10 层，无需担心爆栈
