# P1464 [PacNW 1999] Function

## 题目

定义一个递归函数 $w(a,b,c)$：

1. 若 $a \le 0$ 或 $b \le 0$ 或 $c \le 0$，返回 $1$
2. 若 $a > 20$ 或 $b > 20$ 或 $c > 20$，返回 $w(20,20,20)$
3. 若 $a < b$ 且 $b < c$，返回 $w(a,b,c-1) + w(a,b-1,c-1) - w(a,b-1,c)$
4. 否则返回 $w(a-1,b,c) + w(a-1,b-1,c) + w(a-1,b,c-1) - w(a-1,b-1,c-1)$

输入若干行 `a b c`，以 `-1 -1 -1` 结束。对每行输出 `w(a, b, c) = ans`。

输入数值范围为 $[-2^{63}, 2^{63}-1]$（即 `long long` 范围），行数 ≤ $10^5$。

## 思路

### 直接递归为什么不行

如果不做优化，每次调用 $w$ 会分裂为 3~4 个子调用，重复计算呈指数级增长。对于 $a=b=c=20$，递归树极其庞大，必然 TLE。

### 关键观察：状态空间很小

规则 2 保证：**任何 > 20 的参数都被裁切为 20**。因此实际需要计算的状态只有：

$$0 \le a,b,c \le 20 \quad\Rightarrow\quad 21^3 = 9261\ \text{个状态}$$

> [!note] 类比
> 就像斐波那契：直接递归 $F(n)=F(n-1)+F(n-2)$ 也是指数爆炸的。但因为只有 $n$ 个不同状态，用一个数组 `memo[n]` 记住算过的值，每个状态只算一次，复杂度从 $O(2^n)$ 降到 $O(n)$。
>
> 本题完全一样——把 1D 的斐波那契换成了 3D 的 $w(a,b,c)$。

### 解法：记忆化搜索

用一个 3D 数组 `memo[21][21][21]` 记录已计算的值，初始化为不可能出现的值（如 `-1`）作为"未计算"标记。

每次进入 $w(a,b,c)$：
1. **先处理边界**：`≤0` → 返回 1；`>20` → 裁切到 20
2. **查备忘录**：若 `memo[a][b][c] ≠ -1` → 直接返回
3. **计算并存入**备忘录后返回

---

## 解法

### 记忆化搜索（3D DP）

- **时间复杂度**：$O(21^3) = O(1)$ 预处理 + $O(Q)$ 回答查询（$Q$ 为输入行数）
- **空间复杂度**：$O(21^3) = O(1)$

```cpp
#include <iostream>
#include <cstring>
using namespace std;

long long memo[21][21][21];

long long w(long long a, long long b, long long c) {
    // 规则 1：任意参数 ≤ 0 → 返回 1
    if (a <= 0 || b <= 0 || c <= 0)
        return 1;
    // 规则 2：任意参数 > 20 → 裁切到 20
    if (a > 20 || b > 20 || c > 20)
        return w(20, 20, 20);

    int ai = (int)a, bi = (int)b, ci = (int)c;
    // 查备忘录
    if (memo[ai][bi][ci] != -1)
        return memo[ai][bi][ci];

    // 规则 3：a < b < c
    if (a < b && b < c)
        return memo[ai][bi][ci] =
            w(a, b, c - 1) + w(a, b - 1, c - 1) - w(a, b - 1, c);
    // 规则 4：其它情况
    else
        return memo[ai][bi][ci] =
            w(a - 1, b, c) + w(a - 1, b - 1, c)
          + w(a - 1, b, c - 1) - w(a - 1, b - 1, c - 1);
}

int main() {
    memset(memo, -1, sizeof(memo));  // 初始化为 -1 表示"未计算"

    long long a, b, c;
    while (cin >> a >> b >> c) {
        if (a == -1 && b == -1 && c == -1) break;
        cout << "w(" << a << ", " << b << ", " << c
             << ") = " << w(a, b, c) << "\n";
    }
    return 0;
}
```

### 为什么用 `long long` 而不是 `int`？

1. **输入范围**：题目保证输入在 `[-2^63, 2^63-1]` 内 → 必须用 `long long` 读取
2. **函数返回值**：$w(20,20,20)$ 可能超过 `int` 范围，用 `long long` 更安全
3. **`memset` 初始化**：`memset(_, -1, _)` 对 `long long` 同样有效（每个字节填 `0xFF`，恰好是 `-1` 的补码表示）

### 代码要点分析

| 要点 | 说明 |
|------|------|
| **规则顺序** | 按题目要求的优先级判断：规则 1 → 2 → 3 → 4，不能打乱 |
| **裁切到 20** | `>20` 时调用 `w(20,20,20)` 而非直接改参数——因为三个参数可能有的 >20 有的 ≤20 |
| **类型转换** | `w` 参数用 `long long`（兼容输入），访问 memo 时转为 `int`（已在 [0,20] 范围） |
| **备忘录哨兵** | `-1` 安全：函数值 ≥ 0（规则 1 返回 1，加减组合不会得到 -1） |

## 手动验算

拿样例验证 $w(1,1,1)$ 和 $w(2,2,2)$：

```
w(1,1,1)               规则 3 不满足（1<1 false），走规则 4：
= w(0,1,1) + w(0,0,1) + w(0,1,0) - w(0,0,0)
= 1 + 1 + 1 - 1
= 2  ✓

w(2,2,2)               规则 3 不满足，走规则 4：
= w(1,2,2) + w(1,1,2) + w(1,2,1) - w(1,1,1)

  w(1,2,2): 规则 3（1<2<2? no）→ 规则 4 → 1+1+1-1=2
  w(1,1,2): 规则 3（1<1<2? no）→ 规则 4 → 1+1+1-1=2
  w(1,2,1): 规则 3（1<2<1? no）→ 规则 4 → 1+1+1-1=2
  w(1,1,1): = 2

= 2 + 2 + 2 - 2 = 4  ✓
```

## 总结

1. **问题本质**：递归函数重复计算 → 用记忆化搜索消除冗余
2. **关键观察**：参数 > 20 被裁切 → 状态空间只有 21³ = 9261 → 完全可存储
3. **记忆化模板**：边界检查 → 查备忘录 → 计算 → 存备忘录 → 返回
4. **类型选择**：输入用 `long long`（题目范围），DP 索引用 `int`（已裁切到 0~20）
5. **本题与高精度无关**：虽然输入数值很大，但递归裁切到 20 后返回值完全在 `long long` 范围内
