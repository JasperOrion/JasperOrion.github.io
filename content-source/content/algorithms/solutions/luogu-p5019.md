# P5019 [NOIP 2018 提高组] 铺设道路

## 题目

有 `n` 块连续道路，第 `i` 块的下陷深度为 `d[i]`。每天可以选择一个连续区间，使区间内每块道路的深度减少 1；操作前区间内所有位置都必须为正数。

求将所有深度变为零所需的最少天数。

## 思路一：最大连续非零区间的逐层模拟

对当前的一个极大连续非零区间，区间内所有位置都至少还需要填一层，因此让一次操作覆盖整个区间不会比只覆盖其中一部分更差。

可以不断执行：

1. 找到极大连续非零区间；
2. 将整个区间的深度减一；
3. 某些位置变成零后，原区间可能分裂成多个新区间；
4. 重复直到全部为零。

这个贪心模拟是正确的，但道路深度可能很大，逐层执行会产生大量重复操作，无法满足数据规模要求。

> [!note]
> 关键不是在多个非零区间中寻找长度最大的一个，而是每次操作都应尽量覆盖所在的整个极大非零区间。区间长度不是答案的直接决定因素，横向“层”的数量才是。

## 思路二：反向构造与操作复用

将原问题反过来看：从全零数组开始，每次给一个连续区间增加一层，最终构造出目标深度数组。

从左向右观察：

- 前一位置已经开始的区间操作，只要当前位置仍需要，就尽量继续向右延伸；
- 如果 `d[i] <= d[i - 1]`，当前位置所需的层可以完全复用前面的操作；
- 如果 `d[i] > d[i - 1]`，多出的 `d[i] - d[i - 1]` 层无法从左侧继承，必须在当前位置新开同样数量的区间操作。

因此贪心策略是：

> 最大化复用已经开始的区间，只为每个上升部分支付不可避免的新增操作。

答案为第一块的深度，加上后续所有正向增量：

```text
answer = d[0]

对每个 i >= 1：
    answer += max(0, d[i] - d[i - 1])
```

这与 [贪心算法](/articles/algorithms/concepts/贪心算法/) 中“只支付无法避免的最低成本”一致。

## 差分数组解释

定义 差分数组：

```text
diff[0] = d[0]
diff[i] = d[i] - d[i - 1]
```

差分的含义是：

- `diff[i] > 0`：必须从位置 `i` 新开 `diff[i]` 个区间；
- `diff[i] < 0`：有 `-diff[i]` 个已有区间在前一位置结束；
- `diff[i] = 0`：已有区间全部继续延伸，不需要开始或结束新操作。

所以答案就是差分数组中所有正数之和。

差分并没有让一次操作填充多层，它只是直接统计每一层从哪里开始，从而省去逐层模拟。

## 正确性证明

### 下界：上升部分必须新增操作

考虑相邻位置 `i - 1` 和 `i`。

如果：

```text
d[i] > d[i - 1]
```

那么最多只有 `d[i - 1]` 个经过前一位置的区间能够继续覆盖当前位置。当前位置剩余的：

```text
d[i] - d[i - 1]
```

层不可能从左边延伸而来，至少需要这么多个从当前位置开始的新区间。

第一个位置没有左侧区间可以复用，因此至少需要新开 `d[0]` 个区间。

所以任何合法方案都至少需要：

```text
d[0] + 所有正向差分之和
```

次操作。

### 构造：贪心能够达到下界

从左向右执行：

1. 在第一个位置开始 `d[0]` 个区间；
2. 遇到下降时，结束多余的区间；
3. 遇到上升时，只新开上升差值数量的区间；
4. 其余已有区间尽可能继续向右延伸。

这样能够准确构造每个位置的目标高度，使用的操作数恰好等于上述下界。

算法达到任何方案都无法突破的下界，因此是全局最优解。

## 样例分析

输入深度：

```text
[4, 3, 2, 5, 3, 5]
```

对应差分：

```text
[4, -1, -1, 3, -2, 2]
```

逐项解释：

| 位置变化 | 是否新增操作 | 新增数量 | 累计答案 |
|----------|--------------|---------:|---------:|
| `0 → 4` | 是 | 4 | 4 |
| `4 → 3` | 否 | 0 | 4 |
| `3 → 2` | 否 | 0 | 4 |
| `2 → 5` | 是 | 3 | 7 |
| `5 → 3` | 否 | 0 | 7 |
| `3 → 5` | 是 | 2 | 9 |

答案为：

```text
4 + 3 + 2 = 9
```

## 解法

### 方法一：保存数组后计算正差分

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<long long> depth(n);
    for (long long& value : depth) {
        cin >> value;
    }

    long long answer = depth[0];

    for (int i = 1; i < n; ++i) {
        answer += max(0LL, depth[i] - depth[i - 1]);
    }

    cout << answer << '\n';
    return 0;
}
```

### 方法二：边读边计算

当前答案只依赖前一个深度，不需要保存整个数组。

- 时间复杂度：`O(n)`。
- 额外空间复杂度：`O(1)`。

```cpp
#include <algorithm>
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long answer = 0;
    long long previous = 0;

    for (int i = 0; i < n; ++i) {
        long long current;
        cin >> current;

        answer += max(0LL, current - previous);
        previous = current;
    }

    cout << answer << '\n';
    return 0;
}
```

## 易错点

- 逐层模拟连续非零区间，深度很大时会超时。
- 误以为必须寻找全局最长的非零区间；真正重要的是每个横向层的连续范围。
- 把所有差分都累加；只有正差分代表需要新开操作。
- 忘记第一个位置相当于从高度 0 上升到 `d[0]`。
- 使用 `int` 保存累计答案；使用 `long long` 更安全。
- 将差分当作一次填充多层；差分只是在计数，原操作仍然每次减少一层。

## 总结

- 极大连续非零区间逐层填充是正确但低效的模拟。
- 已开始的区间应尽可能向右延伸，最大化操作复用。
- 每个正向高度差都是无法从左边继承的必要成本。
- 答案等于差分数组中所有正数之和。
- 正差分贪心把逐层模拟优化为一次 `O(n)` 扫描。
