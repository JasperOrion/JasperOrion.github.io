# P3612 [USACO17JAN] Secret Cow Code S

## 题目

> 给定初始字符串 s 和整数 N，按以下规则生成无限字符串：
>
> 每一步：`当前串 → 当前串 + rotate_right(当前串)`
>
> 即把当前串的最末字符移到最前，接到原串后面。求无限字符串中第 N 个字符。
>
> - $|s| \le 30$，$1 \le N \le 10^{18}$

## 思路

### 不能直接构造

字符串每次翻倍，第 k 步的长度是 $|s| \times 2^k$。当 $N = 10^{18}$ 时，需要 $\log_2(10^{18}) \approx 60$ 步，串长达 $10^{18}$ 量级——**不可能实际构造**。

### 逆向思维：从坐标出发

不构造字符串，而是**从大坐标一步步映射回原串**。

设当前长度为 `len`，字符串的结构是：

```
┌─────────────┬──────────────────────────┐
│   左半部分    │     右半部分               │
│  (长度 m)    │  rotate_right(左半部分)     │
│ 0 ... m-1   │ m ... 2m-1               │
└─────────────┴──────────────────────────┘
```

关键问题：**右半部分第 p 个字符（p 从 0 开始）来自左半部分的哪个位置？**

```
左半: a₀  a₁  a₂  ...  a_{m-2}  a_{m-1}
                              ↙
右半: a_{m-1}  a₀  a₁  a₂  ...  a_{m-2}
        ↑        ↑
       p=0      p=1   ...

映射规则：
  p = 0  →  来自左半 m-1 位置（左半最后一个字符）
  p > 0  →  来自左半 p-1 位置
```

### 算法：自顶向下收缩

1. 将 `len` 不断翻倍（`len *= 2`），直到 `len ≥ N`
2. 将 N 转为 0-indexed（`N--`）
3. 当 `len > |s|` 时循环：
   - 若 `N < len/2`：在左半，不需要映射
   - 若 `N == len/2`：映射到 `len/2 - 1`（左半最后一个）
   - 若 `N > len/2`：映射到 `N - 1 - len/2`（右半 p>0 → 左半 p-1）
   - `len /= 2`
4. 输出 `s[N]`

### 手动模拟：`COW 8`

```
初始: s="COW", N=8, len扩到12

N=8 → 0-indexed: N=7

len=12, m=6:
  N=7 > 6 → 右半 p=1 → 映射 N = 7-1-6 = 0, len=6

len=6, m=3:
  N=0 < 3 → 左半，不动, len=3

len=3 = |s|, 退出循环
s[0] = 'C'  ✓
```

## 解法

### 逆向递推

- **时间复杂度**：$O(\log N)$，每次迭代长度减半
- **空间复杂度**：$O(|s|)$，只存原串

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    long long n;
    cin >> s >> n;

    long long len = s.size();

    // 1. 扩展 len 到包含 n 的最小 2^k × |s|
    while (len < n)
        len *= 2;

    // 2. 转 0-indexed
    n--;

    // 3. 从大向小收缩
    while (len > (long long)s.size()) {
        long long m = len / 2;
        if (n == m)
            n = m - 1;          // 右半第一个 → 左半最后一个
        else if (n > m)
            n = n - 1 - m;      // 右半 p>0 → 左半 p-1
        // n < m: 在左半，不动
        len = m;
    }

    cout << s[n] << endl;
    return 0;
}
```

### 映射公式统一写法

有些题解把两个分支合并为一行：

```cpp
while (len > (long long)s.size()) {
    long long m = len / 2;
    if (n >= m)
        n = (n - 1) % m;  // 利用取模统一处理
    len = m;
}
```

推导：当 `n ≥ m` 时，将 `n` 映射回 `[0, m)` 区间。

- `n = m` → `(m-1) % m = m-1` ✓
- `n = m+1` → `m % m = 0` ✓
- `n = m+2` → `(m+1) % m = 1` ✓

这种写法的代码更短，但可读性不如分支写法。

## 核心洞察

这个算法的本质是**函数反演**：

正向生成：$f(pos) = add\_right\_half$

逆向查询：$f^{-1}(pos) =$ 你的映射公式

不需要构造整个字符串，只需对目标坐标反复应用 $f^{-1}$，直到坐标落入原始串范围内。这是处理**指数级扩张问题**的经典模型。

| 正向（构造） | 逆向（查询） |
|------------|------------|
| 从原串出发，倍增构造 | 从目标坐标出发，逐层收缩 |
| 空间 $O(2^k \cdot \|s\|)$ | 空间 $O(\|s\|)$ |
| 指数爆炸 | $O(\log N)$ |

## 总结

1. **不能正向构造**：$N \le 10^{18}$，串长指数增长
2. **逆向递推**：从目标坐标出发，每一步判断在左半还是右半，右半则映射回左半
3. **映射规则**：`rotate_right` 意味着右半第一个字符 = 左半最后一个，其余位置后移一位
4. **复杂度**：$O(\log N)$ 时间，$O(|s|)$ 空间
5. **通用模型**：指数扩张 + 坐标查询 → 逆向反演，无需构造完整结构
