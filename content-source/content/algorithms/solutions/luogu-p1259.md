# P1259 黑白棋子的移动

## 题目

> 初始：n 个白子（o）在左，n 个黑子（\*）在右，末尾 2 个空位（-）。每次**必须将相邻两个棋子一起移动**到空位，且必须跳过若干棋子（不能平移）。最终目标：黑白相间 o\*o\*...，空位移至最左。

输入 n（$4 \le n \le 100$），输出初始状态和每次移动后的状态。

## 思路

### 递归结构

当 n ≥ 4 时，每轮递归用 **2 步**把问题从 n 缩小到 n-1：

```
第 1 步：搬最后一对 "o*" 到空位
第 2 步：搬一对 "*" 到新空位
然后递归处理 n-1
```

当递归到 n = 4 时，用 **5 步固定操作**收尾。

### 为什么 n < 4 时递归公式失效

递归公式假设最左 n 个是 `o`、接着 n 个是 `*`。但当 n=3 时，上一次递归（n=4→3）的第二步已经把两个 `*` 搬到了中间，排列不再是「全部 o 在前、全部 \* 在后」。所以 n ≤ 4 必须用硬编码的收尾序列。

### 递归段：索引公式（0-indexed）

```
┌─────────────────────────────────────────────────────┐
 对于子问题 n (n ≥ 4):                                 
   第 1 步: swap( n-1, n ) ↔ swap( 2n, 2n+1 )         
          = 最后一白 + 第一黑 → 末尾空位                 
   第 2 步: swap( 2n-2, 2n-1 ) ↔ swap( n-1, n )       
          = 末尾两颗黑 → 新空位                         
   然后 solve(n-1)                                    
└─────────────────────────────────────────────────────┘
```

以 n=7 为例验证第一轮：

```
初始: ooooooo*******--       空位在 (14,15)

Step 1: swap(6,7) ↔ (14,15)  搬 (6,7)=o*
  → oooooo--******o*        空位到 (6,7)       ✓

Step 2: swap(12,13) ↔ (6,7)  搬 (12,13)=**
  → oooooo******--o*        空位到 (12,13)     ✓
```

### 收尾段：n=4 的 5 步固定操作

当递归缩到 n=4 时，执行 5 步硬编码收尾：

```
当前状态: ooo*o**--（+ 右侧已排好的交替后缀）

第 1 步: swap(3,4) ↔ (8,9)   搬 o* → 末尾
  → ooo--***o*o*o*o*

第 2 步: swap(6,7) ↔ (3,4)   搬 ** → 新空位
  → ooo*o**--*o*o*o*

第 3 步: swap(1,2) ↔ (6,7)   搬 oo → 空位
  → o--*o**oo*o*o*o*

第 4 步: swap(5,6) ↔ (1,2)   搬 *o → 空位
  → o*o*o*--o*o*o*o*

第 5 步: swap(0,1) ↔ (5,6)   搬 o* → 空位
  → --o*o*o*o*o*o*o*
```

**收尾段的直观理解**：用「搬一对 ↔ 空位移动」做三次交换，把残留的 `ooo*o**` 梳理成交替排列。

## 代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

string s;
int n;

// 打印当前棋盘状态
void print() {
    cout << s << '\n';
}

// 将相邻一对 (from, from+1) 搬到 (to, to+1) 的空位上
// 等价于：swap 两对相邻字符
void move(int from, int to) {
    swap(s[from], s[to]);
    swap(s[from + 1], s[to + 1]);
    print();
}

void solve(int k) {
    if (k == 4) {
        move(8, 3);
        move(3, 7); 
        move(7, 1); 
        move(1, 6); 
        move(6, 0); 
    }
    move(k - 1, 2 * k);
    move(2 * k - 2, k - 1);
    solve(k - 1);
}

int main() {
    cin >> n;

    // 初始化：n 个 o + n 个 * + 2 个 -
    s = string(n, 'o') + string(n, '*') + "--";

    print();        // 输出初始状态
    solve(n);

    return 0;
}
```

| 项目 | 值 |
|------|-----|
| 时间 | O(n)，n 最多 100 |
| 空间 | O(n)，只存一个字符串 |
| 总输出行数 | `2n - 2`（n ≥ 4） |

## 打印格式注意事项

这类「输出每一步状态的构造题」有几个容易踩坑的点：

### 1. 初始状态也要输出

题目要求输出**初始状态和每次移动后的状态**。很多人忘记在第一步递归前 `print()` 初始棋盘。

```cpp
// ✓ 正确
print();    // 初始
solve(n);

// ✗ 错误：漏了初始状态
solve(n);
```

### 2. 不要多输出空行

每行就是棋盘字符串，**结尾不要多余空格**，**行与行之间不要多空行**。OJ 比对是逐行严格匹配的。

```cpp
// ✓ 正确
cout << s << '\n';

// ✗ 错误
cout << s << endl << endl;  // 多了空行
cout << s << " ";           // 多了尾随空格
```

### 3. 索引：0-indexed vs 1-indexed

上面推导用 0-indexed。如果你习惯 1-indexed（用数组 `s[1..2n+2]`），索引公式需要换算：

| 描述 | 0-indexed | 1-indexed |
|------|-----------|-----------|
| 最后一白 + 第一黑 → 空位 | `swap(n-1, n)` ↔ `(2n, 2n+1)` | `swap(n, n+1)` ↔ `(2n+1, 2n+2)` |
| 两黑 → 空位 | `swap(2n-2, 2n-1)` ↔ `(n-1, n)` | `swap(2n-1, 2n)` ↔ `(n, n+1)` |

**建议统一用 0-indexed**，和 C++ `string` 下标保持一致，减少出错。

### 4. 输出行数自检

对 n ≥ 4，总输出行数 = `2n - 2`。可以在本地跑完数一下行数对不对：

```
n=4 → 6 行
n=5 → 8 行
n=7 → 12 行
```

### 5. 递归调用顺序

每次递归内先做 2 步搬动、再对 n-1 递归。顺序不能颠倒——必须先搬动（把 n 缩小为 n-1），再处理更小的子问题。

### 6. n=4 的特殊性

n=4 是递归的终止条件。不满足递归公式的前提（"全 o + 全 \*" 排列已被破坏），必须用硬编码的 5 步收尾。如果 n < 4 也出现在输入中（题目保证 n ≥ 4），需要额外特判。

## 总结

1. **递归分治**：每次 2 步把问题从 n 缩到 n-1，直到 n=4
2. **收尾段是固定的**：n=4 时排列已被打乱，递归公式失效，5 步硬编码收尾
3. **索引推导**：用纸笔画出 n=7 第一轮的两个 swap，归纳出 0-indexed 通用公式
4. **输出纪律**：初始状态 + N 步状态，每行纯字符串，无多余空格空行
5. **行数公式**：`2n - 2`，写完代码后可以本地 `wc -l` 验证
