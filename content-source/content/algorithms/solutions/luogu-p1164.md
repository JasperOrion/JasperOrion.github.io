# P1164 小 A 点菜

## 题目

> N 种菜，第 i 种卖 aᵢ 元，每种只有一份。口袋里有 M 元，必须**刚好花完**。求点菜方案数。

- $1 \le N \le 100$，$1 \le M \le 10000$
- $1 \le a_i \le 1000$
- 答案保证在 `int` 范围内

## 思路

### 问题归类

从 N 个物品中选若干个（每个最多选一次），使它们的和**恰好**等于 M。求方案数。

→ 这是 **0/1 背包的计数变体**：标准的 0/1 背包问"最大价值"（用 `max`），本题问"方案数"（用 `+`）。

### 决策分析

面对第 i 道菜（价格 `a[i]`），只有两种选择：

```
          ┌─ 不点它 → 钱没变，方案数 = 前 i-1 道菜中花完 j 元的方案数
第 i 道菜 ┤
          └─ 点它   → 消耗 a[i] 元，方案数 = 前 i-1 道菜中花完 (j-a[i]) 元的方案数
```

「不点」和「点」是**互斥且完备**的两种决策 → 总方案数 = 两者之和。

---

## 解法一：二维 DP（原始形态）

### 状态定义

```
dp[i][j] = 考虑前 i 道菜，刚好花完 j 元的方案数
```

### 转移方程

$$
dp[i][j] = \begin{cases}
dp[i-1][j] & (j < a_i) \quad\text{钱不够，只能不点} \\[8pt]
dp[i-1][j] + dp[i-1][j - a_i] & (j \ge a_i) \quad\text{不点 + 点}
\end{cases}
$$

### 初始化

```
dp[0][0] = 1    ← 0 道菜、0 元钱：一种方案（什么都不点）
dp[0][j] = 0    ← 0 道菜、j>0 元：不可能完成
```

### 手动模拟

`N=4, M=4, a=[1, 1, 2, 2]`

```
初始化 dp[0][*]:
  dp[0] = [1, 0, 0, 0, 0]

i=1, a=1:
  j=0: dp[1][0]=dp[0][0]=1                    ▸ 不点（钱不够）
  j=1: dp[1][1]=dp[0][1]+dp[0][0]=0+1=1       ▸ 不点 + 点
  j=2: dp[1][2]=dp[0][2]+dp[0][1]=0+0=0
  j=3: dp[1][3]=dp[0][3]+dp[0][2]=0+0=0
  j=4: dp[1][4]=dp[0][4]+dp[0][3]=0+0=0
  dp[1] = [1, 1, 0, 0, 0]

i=2, a=1:
  j=0: dp[2][0]=dp[1][0]=1
  j=1: dp[2][1]=dp[1][1]+dp[1][0]=1+1=2       ▸ 只点1 / 只点2
  j=2: dp[2][2]=dp[1][2]+dp[1][1]=0+1=1       ▸ 点1+点2
  j=3: dp[2][3]=dp[1][3]+dp[1][2]=0+0=0
  j=4: dp[2][4]=dp[1][4]+dp[1][3]=0+0=0
  dp[2] = [1, 2, 1, 0, 0]

i=3, a=2:
  j=0: dp[3][0]=dp[2][0]=1
  j=1: dp[3][1]=dp[2][1]=2                    ▸ 钱不够，不点
  j=2: dp[3][2]=dp[2][2]+dp[2][0]=1+1=2       ▸ 不点 + 点菜3
  j=3: dp[3][3]=dp[2][3]+dp[2][1]=0+2=2       ▸ 不点 + 点菜3+...
  j=4: dp[3][4]=dp[2][4]+dp[2][2]=0+1=1       ▸ 菜1+菜2+菜3
  dp[3] = [1, 2, 2, 2, 1]

i=4, a=2:
  j=0: dp[4][0]=dp[3][0]=1
  j=1: dp[4][1]=dp[3][1]=2
  j=2: dp[4][2]=dp[3][2]+dp[3][0]=2+1=3
  j=3: dp[4][3]=dp[3][3]+dp[3][1]=2+2=4
  j=4: dp[4][4]=dp[3][4]+dp[3][2]=1+2=3       ▸ ★ 最终答案 = 3
  dp[4] = [1, 2, 3, 4, 3]
```

### 关键观察：dp[i] 只依赖 dp[i-1]

从表中可以看到，计算第 i 行时**只需要第 i-1 行的值**：

```
dp[i][j] 依赖 → dp[i-1][j]          (正上方)
              → dp[i-1][j - a[i]]   (左上方)
```

这意味着**我们不需要存整个二维数组** → 解法二。

### 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int N, M;
    cin >> N >> M;

    int a[101];
    for (int i = 1; i <= N; i++)
        cin >> a[i];

    int dp[101][10001] = {0};
    dp[0][0] = 1;

    for (int i = 1; i <= N; i++) {
        for (int j = 0; j <= M; j++) {
            if (j < a[i])
                dp[i][j] = dp[i - 1][j];           // 只能不点
            else
                dp[i][j] = dp[i - 1][j] + dp[i - 1][j - a[i]];  // 不点 + 点
        }
    }

    cout << dp[N][M] << endl;
    return 0;
}
```

| 项目 | 值 |
|------|-----|
| 时间 | O(N × M) |
| 空间 | O(N × M)，约 101 × 10001 × 4B ≈ 4MB |

## 解法二：一维 DP（空间优化）

### 优化原理

因为 `dp[i][j]` 只用到了 `dp[i-1]` 那一行，我们**只用一行数组**滚动更新：

```
把 dp[i-1][*] 存在 dp[*] 中，直接原地更新
```

但这样会遇到一个问题——**覆盖顺序**：

```
如果 j 从小到大遍历：
  更新 dp[2] 时用了 dp[0]（dp[0] 来自上一轮，正确）
  更新 dp[4] 时用了 dp[2]（dp[2] 已被本轮更新！→ 错误：相当于同一道菜用了两次）

如果 j 从大到小遍历：
  更新 dp[4] 时用了 dp[2]（dp[2] 还未被本轮更新，来自上一轮，正确 ✓）
  之后更新 dp[2] 时用了 dp[0]（dp[0] 来自上一轮，正确 ✓）
```

**倒序遍历保证 `dp[j - a[i]]` 永远是上一轮的值**，从而确保每道菜最多选一次。这是 0/1 背包区别于完全背包的唯一标志。

### 直观示意图

```
对于 a[i] = 2, M = 4:

倒序 j: 4 → 3 → 2:
  ┌─────────────────────────────┐
  │ ← 依赖未覆盖方向               │
  │                              │
  │ dp[0] dp[1] dp[2] dp[3] dp[4]
  │                  ↑         ↑
  │             上一轮值   正在更新
  │   (安全读取 ✓)     (写覆盖 ✓)
  └──────────────────────────────┘

正序 j: 2 → 3 → 4:
  ┌─────────────────┐
  │ → 覆盖已更新区域  │
  │                  │
  │ dp[0] dp[1] dp[2] dp[3] dp[4]
  │              ↓         ↑
  │         本轮已覆盖   读取到本轮值
  │         (错误 ✗：同一道菜被用了两次)
  └─────────────────┘
```

### 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int N, M;
    cin >> N >> M;

    int dp[10001] = {0};
    dp[0] = 1;

    for (int i = 0; i < N; i++) {
        int price;
        cin >> price;
        for (int j = M; j >= price; j--) {
            dp[j] += dp[j - price];
        }
    }

    cout << dp[M] << endl;
    return 0;
}
```

| 项目 | 值 |
|------|-----|
| 时间 | O(N × M) |
| 空间 | O(M)，约 10001 × 4B ≈ 40KB |

## 两种写法对比

| 维度 | 二维 DP | 一维 DP |
|------|---------|---------|
| **空间** | O(N × M)，~4MB | O(M)，~40KB |
| **遍历方向** | j 从小到大（自然） | j **必须**从大到小 |
| **可读性** | 直观，每行独立 | 紧凑，需要理解倒序 |
| **恢复方案** | 可以回溯找出具体选了哪些菜 | 需要额外记录 |
| **适合场景** | 理解原理、调试 | 实际比赛（空间更优） |

> **建议**：初学时**先用二维 DP 理解转移逻辑**，确认正确后再优化为一维。两步走能避免"倒序魔咒"——很多初学者直接用一维写错了也不知道为什么。

## 从二维到一维的"翻译"步骤

从二维代码到一维代码只需两步删改：

```cpp
// 二维：
int dp[101][10001] = {0};
dp[0][0] = 1;
for (int i = 1; i <= N; i++) {
    for (int j = 0; j <= M; j++) {
        if (j < a[i])
            dp[i][j] = dp[i-1][j];
        else
            dp[i][j] = dp[i-1][j] + dp[i-1][j-a[i]];
    }
}

// ──→ 删掉第一维 [i]，把 [i-1] 当作"上一轮的 dp"：
// ──→ 倒序遍历 j 以保证读取的是"上一轮"的值：

int dp[10001] = {0};
dp[0] = 1;
for (int i = 0; i < N; i++) {
    int price;
    cin >> price;
    for (int j = M; j >= price; j--) {     // ← 关键：倒序 + 从 price 开始
        dp[j] = dp[j] + dp[j - price];     // ← dp[*] 右边全是上一轮的值
    }
}
```

删除的动作：

| 二维 | 一维 | 原因 |
|------|------|------|
| `dp[i][...]` → `dp[...]` | 去掉第一维 | 原地滚动 |
| `j: 0→M` | `j: M→price` | 倒序避免覆盖 |
| `if (j < a[i])` 分支 | 循环起点 `j=price` | j<price 时 dp 不变，直接跳过 |

## 总结

1. **问题归类**：子集和计数 = 0/1 背包计数型，决策为"选/不选"，运算符用 `+` 而非 `max`
2. **二维状态**：`dp[i][j]` = 前 i 道菜花 j 元的方案数；转移用 `dp[i-1]` 行（上一层）
3. **一维优化原理**：`dp[i]` 只依赖 `dp[i-1]`，可以原地滚动
4. **倒序是 0/1 背包的精髓**：倒序遍历 j，保证 `dp[j-a[i]]` 未被本轮覆盖，仍是上一轮的值
5. **初始化基石**：`dp[0]=1` 代表"恰好花完 0 元"有一种方案（什么都不点），是整个 DP 计数的根基
