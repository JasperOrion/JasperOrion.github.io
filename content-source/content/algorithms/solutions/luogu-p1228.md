# P1228 地毯填补问题

## 题目

> 用 L 型地毯（3 格，4 种朝向）填满 $2^k \times 2^k$ 的方格迷宫，只留公主所在的一格不填。输出每一步放置的地毯位置和形状。
>
> - 输入：k，以及公主坐标 (x, y)（x 为行，y 为列，从 1 开始）
> - 输出：每行 `a b c`，表示在 (a, b) 放置形状为 c 的 L 型地毯

## 思路

### 问题本质

这是经典的**残缺棋盘覆盖问题（Defective Chessboard）**。关键观察：

> $2^k \times 2^k$ 的棋盘挖掉一格后，一定可以用 L 型骨牌完全覆盖。

证明就是分治算法本身——每轮放一块 L 型地毯在棋盘正中心，恰好覆盖另外三个象限各一格，问题就从 $2^k$ 缩为 4 个 $2^{k-1}$ 的子问题。

### 分治策略

把当前方格四等分，公主（或人工空缺）必然落在其中一个象限。在**中心放一块 L 型地毯**，使其盖住另外三个象限的各一格——这三格成为那三个象限的「人工空缺」。然后对四个象限分别递归。

```
         列→
     ┌────────┬────────┐
     │        │        │
     │ 象限1  │ 象限2    │
     │        │        │
     ├────●───┼──●─────┤  ← 中心 2×2：三个 ● 被地毯盖住
 行↓ │    ●   │        │    它们成为三个象限的人工空缺
     │        │        │
     │ 象限3  │ 象限4    │
     │        │        │
     └────────┴────────┘
```

## 坐标分析

### 坐标系

题目规定：x = 行号（从上到下），y = 列号（从左到右）。我们按此定义函数参数：

```cpp
void dfs(int x_left,    // 当前子方格最上方行号
         int y_up,      // 当前子方格最左方列号
         int xj, int yj,// 当前子方格中空缺格子的坐标
         int len)       // 当前子方格边长
```

初始调用：`dfs(1, 1, 公主x, 公主y, 1 << k)`

### 分割线

```cpp
int x = x_left + len / 2;   // 下半区的起始行
int y = y_up  + len / 2;    // 右半区的起始列
```

中心 $2 \times 2$ 的四格是：

```
(x-1, y-1)  ← 左上    (x-1, y)  ← 右上
(x,   y-1)  ← 左下    (x,   y)  ← 右下
```

### 象限判断 + 人工空缺

以 **公主在左上象限**（`xj < x && yj < y`）为例：

```
中心 2×2：
  (x-1, y-1)  ← 公主在此象限，不盖
  (x-1, y)    ← 盖住 → 成为右上象限的人工空缺
  (x,  y-1)   ← 盖住 → 成为左下象限的人工空缺
  (x,  y)     ← 盖住 → 成为右下象限的人工空缺
```

放置形状 1（缺左上角），地毯拐角坐标为 `(x, y)`，然后递归四个象限：

```cpp
cout << x << " " << y << " 1\n";         // 放置地毯
dfs(x_left, y_up,  xj,      yj,      len/2);  // 左上：原公主
dfs(x_left, y,     x - 1,   y,       len/2);  // 右上：人工空缺 (x-1, y)
dfs(x,      y_up,  x,       y - 1,   len/2);  // 左下：人工空缺 (x, y-1)
dfs(x,      y,     x,       y,       len/2);  // 右下：人工空缺 (x, y)
```

四种情况的完整对照表：

| 公主所在象限 | 输出 | 人工空缺（左上/右上/左下/右下） |
|------------|------|------------------------------|
| 左上 | `(x, y, 1)` | 原公主 / `(x-1, y)` / `(x, y-1)` / `(x, y)` |
| 右上 | `(x, y-1, 2)` | `(x-1, y-1)` / 原公主 / `(x, y-1)` / `(x, y)` |
| 左下 | `(x-1, y, 3)` | `(x-1, y-1)` / `(x-1, y)` / 原公主 / `(x, y)` |
| 右下 | `(x-1, y-1, 4)` | `(x-1, y-1)` / `(x-1, y)` / `(x, y-1)` / 原公主 |

> **记忆口诀**：除了公主所在象限保留原空缺，其余三个象限的空缺就是中心 2×2 中除公主对应位置外的另外三格。

## 代码

```cpp
#include <iostream>
using namespace std;

void dfs(int x_left, int y_up, int xj, int yj, int len) {
    if (len == 1)
        return;

    int x = x_left + len / 2;   // 下半区起始行
    int y = y_up  + len / 2;    // 右半区起始列

    if (xj < x && yj < y) {
        // ── 公主在左上 ──
        cout << x << " " << y << " 1\n";
        dfs(x_left, y_up,  xj,      yj,      len / 2);
        dfs(x_left, y,     x - 1,   y,       len / 2);
        dfs(x,      y_up,  x,       y - 1,   len / 2);
        dfs(x,      y,     x,       y,       len / 2);

    } else if (xj < x && yj >= y) {
        // ── 公主在右上 ──
        cout << x << " " << y - 1 << " 2\n";
        dfs(x_left, y_up,  x - 1,   y - 1,   len / 2);
        dfs(x_left, y,     xj,      yj,      len / 2);
        dfs(x,      y_up,  x,       y - 1,   len / 2);
        dfs(x,      y,     x,       y,       len / 2);

    } else if (xj >= x && yj < y) {
        // ── 公主在左下 ──
        cout << x - 1 << " " << y << " 3\n";
        dfs(x_left, y_up,  x - 1,   y - 1,   len / 2);
        dfs(x_left, y,     x - 1,   y,       len / 2);
        dfs(x,      y_up,  xj,      yj,      len / 2);
        dfs(x,      y,     x,       y,       len / 2);

    } else {
        // ── 公主在右下 ──
        cout << x - 1 << " " << y - 1 << " 4\n";
        dfs(x_left, y_up,  x - 1,   y - 1,   len / 2);
        dfs(x_left, y,     x - 1,   y,       len / 2);
        dfs(x,      y_up,  x,       y - 1,   len / 2);
        dfs(x,      y,     xj,      yj,      len / 2);
    }
}

int main() {
    int k, x, y;
    cin >> k >> x >> y;
    dfs(1, 1, x, y, 1 << k);
    return 0;
}
```

| 项目 | 值 |
|------|-----|
| 时间 | $O(4^k)$，即棋盘格子数——每格恰好被覆盖一次 |
| 空间 | $O(k)$，递归深度 |
| 输出行数 | $(4^k - 1) / 3$，可以此自检 |

## 常见错误

### 1. 只递归一个象限（漏了另外三个）

```cpp
// ✗ 错误：只处理公主所在象限
if (xj < x && yj < y) {
    cout << x << " " << y << " 1\n";
    dfs(x_left, y_up, xj, yj, len / 2);   // 只有这一个！
}
```

每放一块地毯，它会在另外三个象限各制造一个空缺。**四个象限都需要递归**。

### 2. 人工空缺坐标写错

最容易出错的是公主在左上时，右上象限的人工空缺坐标：

```cpp
// ✗ 错误
dfs(x_left, y, x, y, len / 2);       // (x, y) 是右下中心格！
// ✓ 正确
dfs(x_left, y, x - 1, y, len / 2);   // (x-1, y) 才是右上中心格
```

**核对方法**：写完一种情况后，反查中心 2×2 四个格子的坐标，逐个确认人工空缺落在正确的象限内。

### 3. 终止条件写成 `len == 0`

```cpp
// ✗ 错误：len 不会变成 0（一直是 2 的幂）
if (len == 0) return;
// ✓ 正确
if (len == 1) return;   // 1×1 的格子无需再分割
```

## 总结

1. **分治核心**：$2^k$ 棋盘 → 中心放 L 型地毯 → 四个 $2^{k-1}$ 子棋盘
2. **人工空缺**：地毯盖住的三格分别成为三个子棋盘的空缺，与原空缺一起驱动递归
3. **坐标陷阱**：Case 1 中 `(x-1, y)` 容易错写成 `(x, y)`，对照中心 2×2 四格核查
4. **递归次数**：每层 4 个分支，不是 1 个——这是分治，不是剪枝
5. **行数自检**：$(4^k - 1) / 3$，$k=3$ 时 21 行，与样例一致
