# 二分查找

在有序序列中通过不断将搜索区间折半来快速定位目标值的算法。时间复杂度 O(log n)。

## 核心方法：红蓝染色法（lowerBound）

定义 `lowerBound(nums, x)`：寻找 **≥ x 的第一个元素的下标**。若不存在则返回 `n`（数组长度）。

### 四种查找需求统一为 lowerBound

| 需求 | 写法 | 若不存在 |
|------|------|----------|
| ≥ x 的第一个元素 | `lowerBound(nums, x)` | n |
| > x 的第一个元素 | `lowerBound(nums, x + 1)` | n |
| < x 的第一个元素 | `lowerBound(nums, x) - 1` | -1 |
| ≤ x 的第一个元素 | `lowerBound(nums, x + 1) - 1` | -1 |

### 区间内元素计数

| 需求 | 写法 |
|------|------|
| < x 的元素个数 | `lowerBound(nums, x)` |
| ≤ x 的元素个数 | `lowerBound(nums, x + 1)` |
| ≥ x 的元素个数 | `n - lowerBound(nums, x)` |
| > x 的元素个数 | `n - lowerBound(nums, x + 1)` |

### 模板代码

```cpp
// 寻找 >= x 的第一个位置的下标
int lowerBound(vector<int>& nums, int x) {
    int left = -1, right = nums.size();
    while (left + 1 != right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < x)
            left = mid;
        else
            right = mid;
    }
    return right; // 返回 >= x 的第一个位置
}
```

### 四种区间写法对照

| 区间 | 循环条件 | mid 给左 | mid 给右 |
|------|----------|----------|----------|
| `(-1, n)` | `left + 1 != right` | `left = mid` | `right = mid` |
| `(-1, n-1]` | `left <= right` | `left = mid` | `right = mid - 1` |
| `[0, n)` | `left <= right` | `left = mid + 1` | `right = mid` |
| `[0, n]` | `left < right` | `left = mid + 1` | `right = mid` |

推荐使用第一种 `(-1, n)` 开区间，逻辑最清晰、不易出错。

## 二分答案

当问题可以转化为"判断某个值是否满足条件"时，对答案值域二分。

核心模式：猜测答案 → check(mid) → 根据结果缩小区间。

```cpp
// 求满足 check(x) == true 的最大整数 x
auto check = [&](int mid) -> bool { /* 判断逻辑 */ };

int left = 最小值 - 1;   // check(left) 恒为 true
int right = 最大值 + 1;  // check(right) 恒为 false
while (left + 1 < right) {
    int mid = left + (right - left) / 2;
    if (check(mid))
        left = mid;
    else
        right = mid;
}
return left; // check 更新的是谁，最终就返回谁
```

## 常见题型

- [34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/) — lowerBound 经典应用：`start = lowerBound(target)`, `end = lowerBound(target+1) - 1`
