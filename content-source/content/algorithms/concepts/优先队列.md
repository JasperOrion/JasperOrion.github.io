# 优先队列

## 定义

优先队列（Priority Queue）是一种每次访问或删除当前最高优先级元素的数据结构。普通队列按照进入顺序取出元素，优先队列按照优先级取出元素。

常见实现是二叉堆：

- 大根堆：堆顶是最大元素；
- 小根堆：堆顶是最小元素。

可以类比医院分诊：普通队列按到达时间处理，优先队列优先处理病情最紧急的人。

## 核心操作

| 操作 | 含义 | 二叉堆复杂度 |
|------|------|--------------|
| `push(x)` | 插入元素 | `O(log n)` |
| `pop()` | 删除堆顶 | `O(log n)` |
| `top()` | 查看堆顶 | `O(1)` |
| `empty()` | 判断是否为空 | `O(1)` |
| `size()` | 返回元素数量 | `O(1)` |

优先队列只保证堆顶是当前最值，不保证其他元素构成完整有序序列。

## C++ 基本用法

头文件：

```cpp
#include <queue>
```

### 大根堆

`priority_queue` 默认是大根堆：

```cpp
priority_queue<int> maxHeap;

maxHeap.push(3);
maxHeap.push(8);
maxHeap.push(1);

cout << maxHeap.top();  // 8
```

### 小根堆

```cpp
#include <functional>
#include <vector>

priority_queue<int, vector<int>, greater<int>> minHeap;

minHeap.push(3);
minHeap.push(8);
minHeap.push(1);

cout << minHeap.top();  // 1
```

模板参数从内到外理解：

```text
int           元素类型
vector<int>   底层容器
greater<int>  比较器，构造小根堆
```

建议使用类型别名：

```cpp
using MinHeap =
    priority_queue<int, vector<int>, greater<int>>;
```

## 读取并删除堆顶

`pop()` 不返回元素，正确写法是：

```cpp
int value = minHeap.top();
minHeap.pop();
```

调用 `top()` 和 `pop()` 前必须确认堆非空：

```cpp
if (!minHeap.empty()) {
    int value = minHeap.top();
    minHeap.pop();
}
```

## `pair` 的优先队列

`pair` 默认按照字典序比较：先比较 `first`，相等时比较 `second`。

### 大根堆

```cpp
priority_queue<pair<int, int>> heap;
```

### 小根堆

```cpp
priority_queue<
    pair<int, int>,
    vector<pair<int, int>>,
    greater<pair<int, int>>
> heap;
```

## 自定义结构体比较

```cpp
struct Node {
    int distance;
    int vertex;
};

struct Compare {
    bool operator()(const Node& a, const Node& b) const {
        return a.distance > b.distance;
    }
};

priority_queue<Node, vector<Node>, Compare> heap;
```

这会让 `distance` 最小的节点位于堆顶，常用于 Dijkstra。

优先队列比较器容易与 `sort` 混淆。基础阶段可以记忆：

```text
priority_queue 默认：大根堆
使用 greater：小根堆
自定义比较器返回 a.key > b.key：较小 key 位于堆顶
```

## P4447 中的嵌套结构

[P4447 分组](/articles/algorithms/solutions/luogu-p4447/) 使用：

```cpp
using MinHeap =
    priority_queue<int, vector<int>, greater<int>>;

map<long long, MinHeap> groups;
```

其中：

- `map` 的键表示小组当前结尾的实力值；
- 小根堆保存所有以该实力值结尾的小组长度；
- 堆顶是其中最短的小组；
- 当前值 `x` 从 `groups[x - 1]` 取出最短组，长度加一后放入 `groups[x]`。

```cpp
auto previous = groups.find(value - 1);

if (previous != groups.end() &&
    !previous->second.empty()) {
    int shortest = previous->second.top();
    previous->second.pop();

    groups[value].push(shortest + 1);
} else {
    groups[value].push(1);
}
```

三个工具的职责不同：

| 工具     | 职责          |
| ------ | ----------- |
| `sort` | 确定队员的处理顺序   |
| `map`  | 按小组结尾实力值分类  |
| 小根堆    | 取得该分类下最短的小组 |

## 与排序的区别

| 对比 | `sort` | 优先队列 |
|------|--------|----------|
| 目标 | 一次性建立完整顺序 | 动态维护当前最值 |
| 插入新元素 | 通常破坏有序状态 | `O(log n)` |
| 取得最值 | 排序后 `O(1)` | `O(1)` |
| 删除最值 | `vector` 中通常需要移动元素 | `O(log n)` |
| 能否随机访问有序元素 | 可以 | 不可以 |
| 典型场景 | 排序后扫描、二分、双指针 | Dijkstra、Huffman、Top K、动态调度 |

完整排序知识见 [排序](/articles/algorithms/concepts/排序/)，C++ API 见 [std::sort 排序函数](/articles/programming/cpp/concepts/std-sort/)。

## 常见应用

- Dijkstra：取得当前距离最小的节点；
- Huffman：反复取出权值最小的两个节点；
- Top K：动态保留最大的或最小的若干元素；
- 合并多个有序序列；
- 任务调度；
- 贪心算法中动态选择当前最优候选。

## 易错点

- 把默认大根堆误认为小根堆。
- 对空堆调用 `top()` 或 `pop()`。
- 误以为 `pop()` 会返回被删除元素。
- 认为优先队列内部所有元素都已完整排序。
- 自定义比较器方向写反。
- 需要按类别分别维护最值，却只使用一个全局优先队列。
