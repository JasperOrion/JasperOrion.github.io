# 滑动窗口

一种在数组/字符串上维护一个动态窗口的算法技巧。核心思想：右指针扩张窗口，左指针收缩窗口，保持窗口满足某种"合法性"，在合法窗口上更新答案。

## 核心框架

```
右指针扩张窗口 → 加入新元素
左指针收缩窗口 → 维护窗口合法性
在合法窗口上更新答案
```

## 分类

### 1. 定长滑动窗口

窗口长度固定为 k，右指针每走一步，左指针跟随。

```cpp
int left = 0;
for (int right = 0; right < n; right++) {
    // 扩张窗口：加入 nums[right]
    if (right - left + 1 == k) {
        // 窗口合法，更新答案
        // 收缩窗口：移除 nums[left]
        left++;
    }
}
```

### 2. 不定长滑动窗口

#### 2.1 最长子数组（求最大长度）

窗口不合法时收缩，合法时更新答案。

```cpp
int ans = 0, left = 0;
for (int right = 0; right < n; right++) {
    // 扩张窗口：加入 nums[right]
    while (窗口不合法) {
        // 收缩窗口
        left++;
    }
    ans = max(ans, right - left + 1);
}
```

#### 2.2 最短子数组（求最小长度）

窗口满足条件时更新答案并尝试收缩。

```cpp
int ans = INF, left = 0;
for (int right = 0; right < n; right++) {
    // 扩张窗口：加入 nums[right]
    while (窗口满足条件) {
        ans = min(ans, right - left + 1);
        left++;  // 尝试缩小
    }
}
```

#### 2.3 求子数组个数

**越短越合法** → `ans += right - left + 1`
- 当右端点固定在 right 时，左端点在 `[left, right]` 的所有子数组都满足要求

**越长越合法** → `ans += left`
- 当右端点固定在 right 时，左端点在 `[0, left-1]` 的所有子数组都满足要求

#### 2.4 恰好型滑动窗口

将"恰好等于 k"转化为"≤ k"减去"≤ k-1"：

```
ans = solve(k) - solve(k-1)
```

封装一个 `solve(limit)` 函数计算 ≤ limit 的子数组个数，两次调用相减即可。
