# 排序

## 定义

排序是按照指定关键字和顺序重新排列一组元素的过程。排序常用于建立处理顺序、二分查找、双指针、贪心决策和数据统计。

## 核心分类

### 升序与降序

- 升序：小元素在前；
- 降序：大元素在前。

### 稳定与不稳定

如果关键字相等的元素在排序后保持原相对顺序，则称排序稳定。

例如只按成绩排序时，两名同分学生是否保持原输入顺序，取决于算法是否稳定。

### 比较排序与非比较排序

- 比较排序：通过比较元素确定顺序，如归并排序、快速排序、堆排序；
- 非比较排序：利用值域特征，如计数排序、基数排序。

基于比较的通用排序，其复杂度下界通常为 `O(n log n)`。

## 常见算法

| 算法 | 平均复杂度 | 最坏复杂度 | 稳定性 | 特点 |
|------|------------|------------|--------|------|
| 冒泡排序 | `O(n²)` | `O(n²)` | 稳定 | 简单，适合教学 |
| 选择排序 | `O(n²)` | `O(n²)` | 不稳定 | 交换次数少 |
| 插入排序 | `O(n²)` | `O(n²)` | 稳定 | 近乎有序时较快 |
| 归并排序 | `O(n log n)` | `O(n log n)` | 稳定 | 需要额外空间 |
| 快速排序 | `O(n log n)` | `O(n²)` | 不稳定 | 实际性能通常较好 |
| 堆排序 | `O(n log n)` | `O(n log n)` | 不稳定 | 原地排序 |

## 排序在贪心中的作用

排序经常用于固定决策顺序。例如：

- 活动安排按结束时间升序；
- P4447 按实力值升序处理；
- 分数背包按单位价值降序；
- Kruskal 按边权升序。

排序本身不是贪心策略，它只是让当前应该选择的元素能够按顺序出现。真正的贪心核心仍然是选择标准和正确性证明。

## C++ `std::sort`

```cpp
sort(values.begin(), values.end());
```

默认按照升序排列。自定义比较器回答：

> `a` 是否应该严格排在 `b` 前面？

```cpp
sort(apples.begin(), apples.end(),
     [](const auto& a, const auto& b) {
         return a.second < b.second;
     });
```

比较器必须使用 `<` 或 `>` 等严格比较，不能使用 `<=` 或 `>=`。

C++ 语法、多关键字排序和 `stable_sort` 详见 [std::sort 排序函数](/articles/programming/cpp/concepts/std-sort/)。

## 排序与优先队列的选型

- 数据全部已知、需要完整顺序：使用排序；
- 数据动态变化、每步只关心最大值或最小值：使用 [优先队列](/articles/algorithms/concepts/优先队列/)；
- 先确定全局处理顺序、再动态选择局部最值：可以同时使用排序和优先队列。

[P4447 分组](/articles/algorithms/solutions/luogu-p4447/) 就是第三种情况。

## 易错点

- 把排序当作贪心算法本身。
- 忽略稳定性要求。
- 多关键字排序没有处理主关键字相等的情况。
- 比较器使用非严格比较。
- 数据动态变化时反复完整排序，导致复杂度过高。
