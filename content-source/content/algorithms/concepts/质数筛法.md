# 质数筛法

高效筛选 [1, n] 范围内所有质数的算法。

## 欧拉筛（线性筛）

时间复杂度 O(n)，每个合数只被其**最小质因子**筛掉一次，是效率最高的筛法。

### 核心思想

1. 遍历 2 到 n 的每个数 i
2. 如果 i 是质数，加入 primes 列表
3. 对于每个已记录的质数 p，标记 `i * p` 为合数
4. 当 `i % p == 0` 时 break——保证每个合数只被最小质因子筛掉

### 模板

```cpp
const int MAXN = 1e6 + 5;
bool is_prime[MAXN];
vector<int> primes;

void euler_sieve(int n) {
    memset(is_prime, true, sizeof(is_prime));
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i <= n; ++i) {
        if (is_prime[i])
            primes.push_back(i);
        for (int p : primes) {
            if (i * p > n) break;
            is_prime[i * p] = false;
            if (i % p == 0) break;  // 关键：保证每个合数只被最小质因子筛掉
        }
    }
}
```

### 为什么是线性的

每个合数 `x` 只会被其**最小质因子**恰好筛一次。当内层循环遇到 `i % p == 0` 时，说明 p 是 i 的最小质因子，此时 p 也是 `i * next_p` 的最小质因子，但 `next_p > p`，所以 `i * next_p` 应该由 p（而非 next_p）在未来的迭代中筛掉——因此 break。
