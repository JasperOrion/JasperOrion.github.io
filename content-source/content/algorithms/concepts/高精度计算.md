# 高精度计算

## 定义

高精度计算（大整数运算）是一类**用数组/字符串模拟手工竖式计算**的技术，用于处理超出标准整数类型（`int`、`long long`）表示范围的整数运算。

## 为什么需要高精度

| 类型 | 最大值 | 十进制位数 |
|------|--------|-----------|
| `int` (32-bit) | ≈ 2.1 × 10⁹ | 10 位 |
| `unsigned int` (32-bit) | ≈ 4.3 × 10⁹ | 10 位 |
| `long long` (64-bit) | ≈ 9.2 × 10¹⁸ | 19 位 |
| `unsigned long long` | ≈ 1.8 × 10¹⁹ | 20 位 |

斐波那契数列 F(5000) ≈ 10¹⁰⁴⁵ —— 远超任何一种标准类型。事实上，很多组合数学和 DP 问题（如[P1255 数楼梯](/articles/algorithms/solutions/luogu-p1255/)）的数据范围就是为此而设计的。

## 核心设计

### 存储方式

采用 `vector<int>` **低位在前**存储（`v[0]` = 个位，`v[1]` = 十位...）：

```
数字 12345678901234567890 存储为：
v = [0, 9, 8, 7, 6, 5, 4, 3, 2, 1, 0, 9, 8, 7, 6, 5, 4, 3, 2, 1]
     个位 ………………………………………………………… 最高位
```

**为什么低位在前？** 因为进位/借位总是从低位向高位传播，低位在前 → `push_back` 即可扩展，无需移动已有元素。

### 输入输出转换

```cpp
// string → vector<int>（低位在前）
vector<int> toVector(const string& s) {
    vector<int> v;
    for (int i = s.size() - 1; i >= 0; i--)
        v.push_back(s[i] - '0');
    return v;
}

// vector<int> → string（高位在前）
string toString(const vector<int>& v) {
    string s;
    for (int i = v.size() - 1; i >= 0; i--)
        s.push_back(v[i] + '0');
    return s;
}
```

### 去前导零

很多运算后会产生前导零（如 `1000 - 999 = 0001`），需要一个辅助函数：

```cpp
void trim(vector<int>& v) {
    while (v.size() > 1 && v.back() == 0)
        v.pop_back();
}
```

> **注意**：保留至少一位。如果结果是 `0`，不是空数组。

### 比较大小

判断 `a >= b`（两个非负数）：

```cpp
bool gte(const vector<int>& a, const vector<int>& b) {
    if (a.size() != b.size())
        return a.size() > b.size();
    for (int i = a.size() - 1; i >= 0; i--)
        if (a[i] != b[i])
            return a[i] > b[i];
    return true;  // a == b
}
```

比较的逻辑：**先比位数，位数相同则从高位向低位逐位比较**。这和手工比较两个数的方法完全一致。

## 加法

**思路**：从低位到高位逐位相加，维护进位 `carry`。

```
以 456 + 789 为例：

  a = [6, 5, 4]    代表 456
  b = [9, 8, 7]    代表 789
  ─────────────────
  i=0: 6+9=15 → 写 5, 进位 1
  i=1: 5+8+1=14 → 写 4, 进位 1
  i=2: 4+7+1=12 → 写 2, 进位 1
  i=3: 进位 1 → 写 1

  res = [5, 4, 2, 1] → 逆序: "1245" ✓
```

```cpp
vector<int> add(const vector<int>& a, const vector<int>& b) {
    vector<int> res;
    int carry = 0;
    for (int i = 0; i < max(a.size(), b.size()) || carry; i++) {
        int sum = carry;
        if (i < a.size()) sum += a[i];
        if (i < b.size()) sum += b[i];
        res.push_back(sum % 10);
        carry = sum / 10;
    }
    return res;
}
```

| 项目 | 值 |
|------|-----|
| **时间复杂度** | O(max(n, m))，n, m 为两数位数 |
| **循环条件** | `i < max(len) || carry` — 别忘了最后的进位！ |

## 减法

**前提**：保证 `a >= b >= 0`（调用前用 `gte()` 判断，若 `a < b` 则交换并加负号）。

```cpp
vector<int> sub(vector<int> a, const vector<int>& b) {
    // 前提: a >= b
    for (int i = 0; i < b.size(); i++) {
        if (a[i] < b[i]) {      // 不够减，向高位借 1
            a[i + 1]--;          // 借位
            a[i] += 10;          // 当前位 +10
        }
        a[i] -= b[i];
    }
    // 处理连锁借位
    for (int i = b.size(); i < a.size(); i++) {
        if (a[i] < 0) {
            a[i + 1]--;
            a[i] += 10;
        }
    }
    trim(a);
    return a;
}
```

**减法要点**：
1. **先判断大小**：`a < b` 时交换，结果加负号
2. **借位可能连锁**：`1000 - 1`，每一位都需要向前借
3. **去除前导零**：`1000 - 999 = 0001` → `trim` 后为 `1`

## 乘法

### 高精度 × 低精度

将一个高精度数乘以一个普通 `int`（假设乘积不溢出 `long long`）。

```cpp
vector<int> mul(const vector<int>& a, int b) {
    vector<int> res;
    long long carry = 0;
    for (int i = 0; i < a.size() || carry; i++) {
        long long prod = carry;
        if (i < a.size()) prod += 1LL * a[i] * b;
        res.push_back(prod % 10);
        carry = prod / 10;
    }
    trim(res);
    return res;
}
```

> 注意 `carry` 和中间结果用 `long long`，因为 `a[i] * b` 最大为 `9 × 10⁹ ≈ 9×10⁹`，`int` 只有 ~2.1×10⁹ 会溢出。

### 高精度 × 高精度

双层循环：`a[i] * b[j]` 贡献给结果的第 `i+j` 位。

```
以 123 × 45 为例：

    a = [3, 2, 1],  b = [5, 4]

    i=0, j=0: a[0]*b[0]=15 → res[0]=5, 进位 1
    i=0, j=1: a[0]*b[1]=12 + 1 = 13 → res[1]=3, 进位 1
    i=1, j=0: a[1]*b[0]=10 + 1 = 11 → res[1]=1, 进位 2
    ...

    res = [5, 3, 5, 5] → 逆序 → "5535" ✓
```

```cpp
vector<int> mul(const vector<int>& a, const vector<int>& b) {
    vector<int> res(a.size() + b.size(), 0);
    for (int i = 0; i < a.size(); i++) {
        for (int j = 0; j < b.size(); j++) {
            res[i + j] += a[i] * b[j];
        }
    }
    // 统一处理进位
    int carry = 0;
    for (int i = 0; i < res.size(); i++) {
        res[i] += carry;
        carry = res[i] / 10;
        res[i] %= 10;
    }
    trim(res);
    return res;
}
```

| 项目 | 值 |
|------|-----|
| **时间复杂度** | O(n × m) |
| **结果位数** | 最多 n + m 位（9×9=81，每对贡献 ≤ 2 位） |
| **关键技巧** | 先累加再统一进位，避免每步进位 |

## 除法（高精度 ÷ 低精度）

从高位到低位逐位试商，余数传给下一位。**这和手工长除法的方向一致（从高位开始）**。

```cpp
// 返回 {商, 余数}
pair<vector<int>, int> div(const vector<int>& a, int b) {
    vector<int> q;
    long long r = 0;  // 当前余数
    for (int i = a.size() - 1; i >= 0; i--) {
        r = r * 10 + a[i];     // 余数 × 10 + 当前位 = 当前被除数
        q.push_back(r / b);     // 商
        r %= b;                 // 更新余数
    }
    // q 现在是高位在前，需要翻转
    reverse(q.begin(), q.end());
    trim(q);
    return {q, (int)r};
}
```

```
例：1234 ÷ 5

  a = [4, 3, 2, 1]（逆序后从高位遍历）
  i=3: r=0→1/5=0, r=1
  i=2: r=1→12/5=2, r=2
  i=1: r=2→23/5=4, r=3
  i=0: r=3→34/5=6, r=4

  q = [0,2,4,6] → reverse → [6,4,2,0] → trim → [6,4,2] → 246, r=4
```

> **注意**：`r` 用 `long long`，保证 `r * 10 + a[i]` 不溢出。`b` 是 `int` 所以结果安全。

### 高精度 ÷ 高精度

高精度除法的最常用做法是**二分商 + 高精度乘法验证**，或使用**减法模拟**。复杂度较高（O(n²)），不在入门范围。用 Python / Java 解决此类问题时，可直接使用语言内置的任意精度整数。

## 完整模板（速查）

```cpp
#include <vector>
#include <string>
#include <algorithm>
using namespace std;
using BigInteger = vector<int>;

// 输入输出
BigInteger toBig(const string& s) {
    BigInteger v;
    for (int i = s.size() - 1; i >= 0; i--)
        v.push_back(s[i] - '0');
    return v;
}
string toStr(const BigInteger& v) {
    string s;
    for (int i = v.size() - 1; i >= 0; i--)
        s.push_back(v[i] + '0');
    return s;
}
void trim(BigInteger& v) {
    while (v.size() > 1 && v.back() == 0)
        v.pop_back();
}

// 比较
bool gte(const BigInteger& a, const BigInteger& b) {
    if (a.size() != b.size()) return a.size() > b.size();
    for (int i = a.size() - 1; i >= 0; i--)
        if (a[i] != b[i]) return a[i] > b[i];
    return true;
}

// 加法
BigInteger add(const BigInteger& a, const BigInteger& b) {
    BigInteger res;
    int carry = 0;
    for (int i = 0; i < max(a.size(), b.size()) || carry; i++) {
        if (i < a.size()) carry += a[i];
        if (i < b.size()) carry += b[i];
        res.push_back(carry % 10);
        carry /= 10;
    }
    return res;
}

// 减法 (a >= b)
BigInteger sub(BigInteger a, const BigInteger& b) {
    for (int i = 0; i < b.size(); i++) {
        if (a[i] < b[i]) a[i + 1]--, a[i] += 10;
        a[i] -= b[i];
    }
    for (int i = b.size(); i < a.size(); i++)
        if (a[i] < 0) a[i + 1]--, a[i] += 10;
    trim(a);
    return a;
}

// 乘法：高 × 低
BigInteger mul(const BigInteger& a, int b) {
    BigInteger res;
    long long carry = 0;
    for (int i = 0; i < a.size() || carry; i++) {
        if (i < a.size()) carry += 1LL * a[i] * b;
        res.push_back(carry % 10);
        carry /= 10;
    }
    trim(res);
    return res;
}

// 乘法：高 × 高
BigInteger mul(const BigInteger& a, const BigInteger& b) {
    BigInteger res(a.size() + b.size(), 0);
    for (int i = 0; i < a.size(); i++)
        for (int j = 0; j < b.size(); j++)
            res[i + j] += a[i] * b[j];
    int carry = 0;
    for (int i = 0; i < res.size(); i++)
        res[i] += carry, carry = res[i] / 10, res[i] %= 10;
    trim(res);
    return res;
}

// 除法：高 ÷ 低 → {商, 余数}
pair<BigInteger, int> div(const BigInteger& a, int b) {
    BigInteger q;
    long long r = 0;
    for (int i = a.size() - 1; i >= 0; i--) {
        r = r * 10 + a[i];
        q.push_back(r / b);
        r %= b;
    }
    reverse(q.begin(), q.end());
    trim(q);
    return {q, (int)r};
}
```
