# 最大公约数与最小公倍数

## 最大公约数（GCD）

### 欧几里得算法（辗转相除法）

核心公式：`gcd(a, b) = gcd(b, a % b)`，直到 `b == 0` 时返回 `a`。

```cpp
int gcd(int a, int b) {
    if (b == 0)
        return a;
    return gcd(b, a % b);
}
```

时间复杂度 O(log min(a, b))。

### C++17 内置函数

```cpp
#include <numeric>
int g = std::gcd(a, b);
```

## 最小公倍数（LCM）

公式：`lcm(a, b) = a / gcd(a, b) * b`

> **注意**：先除后乘，防止溢出。

```cpp
int lcm(int a, int b) {
    return a / gcd(a, b) * b;
}
```

C++17 内置：`std::lcm(a, b)`
