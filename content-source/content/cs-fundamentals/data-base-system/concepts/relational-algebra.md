# 关系代数运算

> 关系代数：用运算符对关系（表）进行操作，得到新关系。是 SQL 的数学基础。

## 1. 集合运算符

| 运算 | 记法 | 含义 |
|------|------|------|
| 并 | R ∪ S | R 和 S 中所有元组合并，去重。要求 R、S 同列。 |
| 差 | R − S | 在 R 中但不在 S 中的元组。要求同列。 |
| 交 | R ∩ S | 同时在 R 和 S 中的元组。要求同列。 |
| 广义笛卡尔积 | R × S | R 每行与 S 每行两两拼接。列数 = R列数 + S列数，行数 = R行数 × S行数。 |
| 象集 | — | 给定 R(X, Y) 和一个 X 值 x，x 在 R 中的象集 Zₓ = { 与 x 配对的 Y 值 }。是"除"运算的基础。 |

## 2. 关系运算符

| 运算 | 记法 | 含义 |
|------|------|------|
| 选择 | σ<sub>条件</sub>(R) | 从 R 中挑出**满足条件的行**（水平切）。例：σ<sub>年龄>20</sub>(学生) |
| 投影 | π<sub>列名</sub>(R) | 从 R 中挑出**指定列**（垂直切），自动去重。例：π<sub>姓名,系别</sub>(学生) |
| 连接 | R ⋈<sub>条件</sub> S | R 和 S 按条件拼接行。无条件的连接 = 笛卡尔积。 |
| ↳ 等值连接 | R ⋈<sub>R.A=S.B</sub> S | 条件为等号 `=` 的连接。 |
| ↳ 自然连接 | R ⋈ S | 在**同名属性**上自动做等值连接，且**同名属性只保留一列**。 |
| ↳ 外连接 | R ⟕ S / R ⟖ S / R ⟗ S | 保留悬浮元组（不满足连接条件的行），缺失属性填 NULL。左外=保留左表、右外=保留右表、全外=两边都保留。 |
| ↳ 悬浮元组 | — | 在连接中因不满足条件而被丢弃的行。 |
| 除 | R ÷ S | 找出 R 中那些与 S **所有值**都关联的属性值（见下方解题方法）。 |

> **选择 vs 投影**：选择挑行（水平），投影挑列（垂直）。口诀——**选行投列**。

## 3. 解题方法

### 3.1 除运算（求"满足全部"）

> R ÷ S：找出 R 中与 S **所有**值都匹配的属性值。

**步骤**：
1. 设 R(X, Y)，S(Y)，求 R ÷ S 在 X 上的结果
2. 列出 R 中所有 X 值，对每个 X 值，检查其 Y 集合是否**包含** S 的所有 Y 值
3. 若包含，该 X 值入选

**例**：求"选修了**全部**课程的学生"

| R（选课） | S（课程） |
|----------|---------|
| 学号 课程号 | 课程号 |
| S1 C1 | C1 |
| S1 C2 | C2 |
| S2 C1 | |

R ÷ S = {S1}（只有 S1 选了全部 C1 和 C2）

### 3.2 差运算（求"没有"）

> R − S：在 R 中但不在 S 中的元组。

**例**：求"没有选修 C1 的学生"

π<sub>学号</sub>(学生) − π<sub>学号</sub>(σ<sub>课程号='C1'</sub>(选课))

### 3.3 常用组合

| 需求 | 写法 |
|------|------|
| "至少选了 X 和 Y" | π(σ<sub>X</sub>) ∩ π(σ<sub>Y</sub>) |
| "选了 X 但没选 Y" | π(σ<sub>X</sub>) − π(σ<sub>Y</sub>) |
| "同时满足多个条件" | 用 ∧ 连接，或多次选择后取 ∩ |
