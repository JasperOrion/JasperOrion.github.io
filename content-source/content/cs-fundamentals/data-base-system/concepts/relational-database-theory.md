# 关系数据库理论

## 1. 逻辑蕴含（Armstrong 公理系统）

从已知函数依赖推导出新函数依赖的三条推理规则：

| 公理 | 规则 | 说明 |
|------|------|------|
| **自反率** | 若 Y ⊆ X ⊆ U，则 X → Y | 大集合能决定自己的子集（平凡依赖的来源） |
| **增广率** | 若 X → Y，则 XZ → YZ | 两边同时加相同属性，依赖仍成立 |
| **传递率** | 若 X → Y 且 Y → Z，则 X → Z | 依赖的链式传递 |

> 这三条是**完备的**：任何能从 F 推导出的函数依赖，都可以通过反复使用这三条公理得到。

## 2. 闭包的计算

### 定义

设 F 是属性集 U 上的一组函数依赖，X ⊆ U。X 关于 F 的闭包 **X⁺** 定义为：

> X⁺ = { A | X → A 能由 F 根据 Armstrong 公理推导出来 }

通俗理解：**从属性集合 X 出发，反复根据 F 中的函数依赖关系推导，能推出的所有属性的集合。**

### 计算步骤

1. 初始化：X⁺ = X
2. 重复以下操作，直到 X⁺ 不再变化：
   - 扫描 F 中每一条函数依赖 Y → Z
   - 若 Y ⊆ X⁺，则将 Z 加入 X⁺
3. 最终 X⁺ 即为所求的闭包

### 核心要点

1. **左部 ⊆ X⁺ 就能用**：函数依赖 Y → Z 中，Y 的所有属性都在当前 X⁺ 里，就把 Z 加进来。
2. **反复扫描直到不变**：每轮可能有新的属性加入，需要重新扫描所有 FD。
3. **闭包用途**：
   - 判断 **X 是否是超码**：若 X⁺ = U，则 X 是超码
   - 判断 **函数依赖 X → Y 是否成立**：若 Y ⊆ X⁺，则 X → Y 成立
   - 求**候选码**的基础

### 例题

**题目 1**：已知 U = {A, B, C, D, E}，F = {AB → C, C → D, D → E}，求 AB⁺。

| 轮次 | 当前 X⁺ | 使用的 FD | 新加入 | 结果 X⁺ |
|------|---------|----------|--------|---------|
| 初始 | {A, B} | — | — | {A, B} |
| 第 1 轮 | {A, B} | AB → C（左部 AB ⊆ {A, B}） | C | {A, B, C} |
| 第 2 轮 | {A, B, C} | C → D（左部 C ⊆ {A, B, C}） | D | {A, B, C, D} |
| 第 3 轮 | {A, B, C, D} | D → E（左部 D ⊆ {A, B, C, D}） | E | {A, B, C, D, E} |
| 第 4 轮 | {A, B, C, D, E} | 无新的可加入 | — | {A, B, C, D, E} ✓ |

**答案**：AB⁺ = U，说明 AB 是候选码。

**题目 2**：同上 F，求 B⁺。

| 轮次 | 当前 X⁺ | 使用的 FD | 判断 | 结果 X⁺ |
|------|---------|----------|------|---------|
| 初始 | {B} | — | — | {B} |
| 第 1 轮 | {B} | AB → C | B ≠ {A, B}，左部不 ⊆ X⁺，跳过 | {B} |
| 第 1 轮 | {B} | C → D | C ⊈ {B}，跳过 | {B} |
| 第 1 轮 | {B} | D → E | D ⊈ {B}，跳过 | {B} |
| 结束 | {B} | 所有 FD 均无法使用 | — | {B} ✓ |

**答案**：B⁺ = {B}，B 不能单独推导出任何其他属性。

## 3. 最小函数依赖集

### 定义

如果函数依赖集 F 满足以下三个条件，则称 F 为**最小函数依赖集**（也称**最小覆盖**）：

> 1. F 中每个函数依赖的**右部都是单属性**
> 2. F 中没有**多余的函数依赖**（去掉任意一条，剩下的依赖不再等价于原 F）
> 3. F 中每条函数依赖的**左部没有多余属性**（左部去掉任意属性后，该依赖不再成立）

### 求解步骤

#### 第一步：拆分右侧（使右部单属性化）

将 F 中所有右部有多个属性的依赖拆开。例：A → BC 拆成 A → B 和 A → C。

#### 第二步：去除多余的函数依赖

对 F 中**每一条**函数依赖 X → Y：
- 假设删掉它，得到 F' = F − {X → Y}
- 求 X 关于 F' 的闭包 X⁺
- 若 Y ⊆ X⁺，说明 X → Y 可以由其他依赖推导出 → **删掉**
- 否则保留

⚠️ **关键**：删掉一条后，F 变小了，下一条检验要在**新的 F** 上进行。

#### 第三步：左侧最小化

对 F 中**每一条**函数依赖 X₁X₂…Xₙ → Y（n ≥ 2）：
- 对左部的**每个属性** Xᵢ：
  - 去掉 Xᵢ，得到新的左部 X' = X − {Xᵢ}
  - 求 X' 关于**原 F** 的闭包 X'⁺
  - 若 Y ⊆ X'⁺，说明 Xᵢ 是冗余属性 → **删掉 Xᵢ**

### 例题 1（基础）

**题目**：F = {AB → C, C → D, D → E, AB → A}，求最小函数依赖集。

**第一步**：右部全部单属性 ✓，无需拆分。

**第二步**：逐条检查

| 待删依赖 | F'（去掉后） | 求闭包 | 判断 | 操作 |
|----------|-------------|--------|------|------|
| AB → C | {C → D, D → E, AB → A} | AB⁺ = {A, B} | C ⊈ {A, B} | **保留** |
| C → D | {AB → C, D → E, AB → A} | C⁺ = {C} | D ⊈ {C} | **保留** |
| D → E | {AB → C, C → D, AB → A} | D⁺ = {D} | E ⊈ {D} | **保留** |
| AB → A | {AB → C, C → D, D → E} | AB⁺ = U | A ⊆ U | **删掉** ✓ |

> AB → A 是平凡的（A 本来就在 AB 里），能被其他依赖推导 → 多余。

现在 F = {AB → C, C → D, D → E}

**第三步**：左侧最小化——AB → C 左部有两个属性：
- 去掉 A：B⁺ = {B}，C ⊈ {B} → A 不可删
- 去掉 B：A⁺ = {A}，C ⊈ {A} → B 不可删

**最终结果**：{AB → C, C → D, D → E}

### 例题 2（含冗余属性）

**题目**：F = {AB → C, A → B, B → D}，求最小函数依赖集。

**第一步**：右部全是单属性 ✓

**第二步**：

| 待删依赖 | F' | 求闭包 | 判断 |
|----------|-----|--------|------|
| AB → C | {A → B, B → D} | AB⁺ = {A, B, D} | C ⊈ AB⁺ → **保留** |
| A → B | {AB → C, B → D} | A⁺ = {A} | B ⊈ A⁺ → **保留** |
| B → D | {AB → C, A → B} | B⁺ = {B} | D ⊈ B⁺ → **保留** |

**第三步**：AB → C——去掉 A：B⁺ = {B, D}（用到 B → D），C ⊈ → A 不可删；去掉 B：A⁺ = {A, B}（用到 A → B），C ⊈ → B 不可删。

**最终结果**：{AB → C, A → B, B → D}

### 例题 3（多冗余依赖，重点）

**题目**：F = {A→B, A→C, A→D, C→D, BD→E, AC→B, AC→E}，求最小函数依赖集。

**第一步**：右部全是单属性 ✓

**第二步**：逐条检查（顺序处理，删一条后立即更新 F）

**① 检验 A→B**：F' = {A→C, A→D, C→D, BD→E, AC→B, AC→E}

```
{A} → A→C 触发 → {A, C}
→ A→D 触发 → {A, C, D}
→ C→D 触发 → D 已有
→ AC→B 触发（A,C⊆闭包）→ {A, B, C, D}  ← 关键！
→ BD→E 触发（B,D⊆闭包）→ {A, B, C, D, E}
→ AC→E 触发 → E 已有
```

A⁺ = U，B ⊆ U → **A→B 多余，删掉** ✓。F 变为：{A→C, A→D, C→D, BD→E, AC→B, AC→E}

**② 检验 A→C**：F' = {A→D, C→D, BD→E, AC→B, AC→E}

```
{A} → A→D 触发 → {A, D}
→ C→D 不触发（C∉闭包）
→ AC→B 不触发（C∉闭包）
```

A⁺ = {A, D}，C ⊈ A⁺ → **保留** ✓

**③ 检验 A→D**：F' = {A→C, C→D, BD→E, AC→B, AC→E}

```
{A} → A→C 触发 → {A, C}
→ C→D 触发 → {A, C, D}  ← D 进来了！
→ AC→B 触发 → {A, B, C, D}
→ BD→E 触发 → U
→ AC→E 触发 → E 已有
```

A⁺ = U，D ⊆ U → **A→D 多余，删掉** ✓。F 变为：{A→C, C→D, BD→E, AC→B, AC→E}

**④ 检验 C→D**：F' = {A→C, BD→E, AC→B, AC→E}

C⁺ = {C}，D ⊈ → **保留** ✓

**⑤ 检验 BD→E**：F' = {A→C, C→D, AC→B, AC→E}

BD⁺ = {B, D}（所有 FD 左部都不 ⊆ {B, D}），E ⊈ → **保留** ✓

**⑥ 检验 AC→B**：F' = {A→C, C→D, BD→E, AC→E}

```
{A, C} → A→C 触发 → C 已有
→ C→D 触发 → {A, C, D}
→ AC→E 触发 → {A, C, D, E}
→ BD→E 不触发（B∉闭包）
```

AC⁺ = {A, C, D, E}，B ⊈ → **保留** ✓

**⑦ 检验 AC→E**：F' = {A→C, C→D, BD→E, AC→B}

```
{A, C} → A→C 触发 → C 已有
→ C→D 触发 → {A, C, D}
→ AC→B 触发 → {A, B, C, D}  ← B 进来了！
→ BD→E 触发 → U  ← E 进来了！
```

AC⁺ = U，E ⊆ U → **AC→E 多余，删掉** ✓。F 变为：{A→C, C→D, BD→E, AC→B}

**第二步小结**：删了 3 条 → F = {A→C, C→D, BD→E, AC→B}

**第三步**：左侧最小化

- **AC→B**（左部 = {A, C}）：
  - 去 C（检验 A→B）：A⁺ = {A→C, C→D, AC→B, BD→E} = U，B ⊆ U → **C 冗余** → 化简为 **A→B**
  - 去 A（检验 C→B）：C⁺ = {C, D}，B ⊈ → A 不可删
- **BD→E**：去 B → D⁺ = {D}, E ⊈；去 D → B⁺ = {B}, E ⊈。均不可删。

**最终结果**：{**A→B**, **A→C**, **C→D**, **BD→E**}（合并 A 左部 → {**A→BC**, **C→D**, **BD→E**}）

**验证**（回到原始 F 检查是否等价）：

| FD | 能否从 F_min 推出？ |
|----|-------------------|
| A→B | ✓ 就在 F_min 中 |
| A→C | ✓ 就在 F_min 中 |
| A→D | ✓ A→C + C→D 传递 |
| C→D | ✓ 就在 F_min 中 |
| BD→E | ✓ 就在 F_min 中 |
| AC→B | ✓ A→B（A 单独就能推 B） |
| AC→E | ✓ A→B + BD→E + A→C + C→D |

全部可推出，等价 ✓

### 快速检验技巧

得到结果后，用这 3 条检验：
1. ✅ 每条右部都是单属性？
2. ✅ 去任意一条，剩下推不出它？
3. ✅ 去左部任意属性，该依赖不再成立？

## 4. 函数依赖

1. **非平凡函数依赖**：X → Y 且 Y ⊈ X。例：学号 → 姓名
2. **平凡函数依赖**：X → Y 且 Y ⊆ X。例：(学号, 课程号) → 学号
3. **完全函数依赖**：X → Y，且 X 的任何真子集都不能决定 Y。记作 X ⟶ᶠ Y。例：(学号, 课程号) → 成绩
4. **部分函数依赖**：X → Y，但 X 的某个真子集也能决定 Y。记作 X ⟶ᵖ Y。例：(学号, 课程号) → 系别
5. **传递函数依赖**：X → Y，Y → Z，且 Y ↛ X，则 X → Z 是传递依赖。例：学号 → 系号，系号 → 系主任

## 5. 码

| 术语 | 定义 |
|------|------|
| **候选码** | 能唯一标识一个元组的**最小**属性组。满足：(1) 能推出 U 中所有属性；(2) 任何真子集都不能推出 U。一个关系可有多个候选码。 |
| **主码** | 从候选码中选出的**一个**，作为关系的主键（用下划线标记）。 |
| **超码** | 能唯一标识元组的属性组（不要求最小）。候选码是"最小超码"。 |
| **主属性** | 包含在**任意候选码**中的属性。 |
| **非主属性** | 不包含在**任何候选码**中的属性。 |
| **外码** | 一个关系 R 中的属性组，它对应另一个关系 S 的主码。用于表间关联。 |
| **全码** | 整个属性组 U 共同构成候选码（任何一个真子集都不够）。 |

### 候选码求解例题

已知 U = {A, B, C, D, E, G}，F = {AB→C, CD→E, E→A, A→G}，求候选码。

**第一步：属性分类**
- 一定属于候选码：B, D（从未出现在任何 FD 右部）
- 可能属于候选码：A, C, E（左右都出现过）
- 一定不属于候选码：G（只出现在右部）

**第二步：闭包运算**

| 尝试的属性组 | 闭包计算 | 结果 | =U? |
|------------|---------|------|-----|
| {B, D} | 无FD可用 | {B, D} | ❌ |
| {B, D, A} | A→G 得 G, AB→C 得 C, CD→E 得 E | U | ✅ |
| {B, D, C} | CD→E 得 E, E→A 得 A, A→G 得 G | U | ✅ |
| {B, D, E} | E→A 得 A, A→G 得 G, AB→C 得 C | U | ✅ |

**答案**：候选码有 3 个 → {B, D, A}、{B, D, C}、{B, D, E}

## 6. 范式

### 各范式定义

| 范式 | 核心要求 | 说明 |
|------|---------|------|
| **1NF** | 属性不可再分 | 每个字段都是原子值（最基本要求，关系数据库默认满足） |
| **2NF** | 1NF + 消除非主属性对码的**部分函数依赖** | 非主属性必须完全依赖于码（不能只依赖码的一部分） |
| **3NF** | 2NF + 消除非主属性对码的**传递函数依赖** | 非主属性不能通过另一个非主属性间接依赖于码 |
| **BCNF** | 3NF + 消除主属性对码的部分和传递依赖 | 每个决定因素（左部）都必须包含码 |

### 判断范式的通用方法

1. **找出候选码**（用闭包法）
2. **找出主属性**（属于任意候选码的属性）和**非主属性**
3. **按顺序检查**：
   - 先检查 2NF：非主属性有没有部分依赖于码？
   - 再检查 3NF：非主属性有没有传递依赖于码？
   - 最后检查 BCNF：每条函数依赖的左部是否都包含码？

### 范式判断速查表

| 条件 | 不满足 → 属于哪级 |
|------|-----------------|
| 属性可再分 | 连 1NF 都不是 |
| 存在非主属性**部分依赖**于码 | 最高 1NF |
| 存在非主属性**传递依赖**于码 | 最高 2NF |
| 存在决定因素（FD 左部）**不含码** | 最高 3NF |
| 以上全满足 | BCNF |

**口诀**：部分依赖→破 2，传递依赖→破 3，左部非码→破 B

### 例题 1：判断范式等级

**题目**：R(U)，U = {Sno, Cno, Grade, Sdept}，F = {(Sno, Cno) → Grade, Sno → Sdept}。判断 R 属于第几范式。

1. **候选码**：(Sno, Cno)⁺ = U → 候选码 = (Sno, Cno)
2. **主属性**：Sno, Cno；**非主属性**：Grade, Sdept
3. 检查 2NF：
   - Grade：完全依赖 (Sno, Cno) ✓
   - Sdept：只依赖 Sno（码的一部分）→ 部分依赖 ❌

**答案**：R 属于 **1NF**（不满足 2NF）。

### 例题 2：逐步提升范式

**题目**：R(U) = {学号, 姓名, 课程号, 课程名, 成绩}，F = {学号 → 姓名, 课程号 → 课程名, (学号, 课程号) → 成绩}。

**候选码**：(学号, 课程号)
**主属性**：学号, 课程号；**非主属性**：姓名, 课程名, 成绩

**当前状态**：非主属性**姓名**只依赖学号（码的一部分）→ 部分依赖 → **1NF**

**分解到 2NF**（将部分依赖拆出去）：
- R₁(学号, 姓名)，码 = 学号
- R₂(课程号, 课程名)，码 = 课程号
- R₃(学号, 课程号, 成绩)，码 = (学号, 课程号)

三个子模式都满足 2NF ✓。继续检查 3NF：
- R₁/R₂ 只有一步依赖 → 3NF ✓
- R₃：成绩直接依赖码 → 3NF ✓

### 例题 3：3NF 但不满足 BCNF

**题目**：R(U) = {学生, 老师, 课程}，F = {老师 → 课程, (学生, 课程) → 老师}。语义：每个老师只教一门课。

1. **候选码**：(学生, 课程) → (学生, 课程, 老师) = U ✓；(学生, 老师) → (学生, 课程) = U ✓
   → 候选码 = (学生, 课程) 和 (学生, 老师)
2. **主属性**：学生, 课程, 老师。**无非主属性**。
3. 2NF/3NF 自动满足 ✓
4. BCNF：**老师 → 课程**，左部是 {老师}，不包含任何候选码 → ❌

**答案**：R 属于 **3NF**，但不属于 **BCNF**。

**分解到 BCNF**：将违反 BCNF 的 FD 拆成单独关系
- R₁(老师, 课程)，码 = 老师
- R₂(学生, 老师)，码 = (学生, 老师)（全码）

### 例题 4：逐层提升到 3NF（完整流程）

**题目**：U = {A, B, C, D, E}，F = {AD→B, B→C}。判断属于第几范式，并逐层分解到 3NF。

**第一步：求候选码**——E 不出现在任何 FD 右部 → 必属于候选码。

| 尝试 | 闭包计算 | 结果 |
|------|---------|------|
| {A, D, E} | AD→B 得 B → B→C 得 C | U ✅ |
| {A, E} | 无 FD 可用 | ≠U ❌ |
| {D, E} | 无 FD 可用 | ≠U ❌ |

**候选码 = {A, D, E}**（唯一）

**第二步**：主属性 = A, D, E；非主属性 = B, C

**第三步：判断当前范式**

| 非主属性 | FD | 判定 |
|---------|-----|------|
| B | AD→B，AD ⊂ ADE | **部分依赖** ❌ |
| C | B→C，B 部分依赖码 | 间接部分依赖 ❌ |

🔴 存在部分依赖 → **最高 1NF**

**第四步：分解到 2NF**（消除部分依赖）
- R₁(**A**, **D**, B, C)，码 = AD，FD = {AD→B, B→C}
- R₂(**A**, **D**, **E**)，码 = ADE

**第五步：分解到 3NF**（消除传递依赖）——R₁ 中 AD→B→C 是传递依赖 ❌
- R₁₁(**A**, **D**, B)，码 = AD，FD = {AD→B}
- R₁₂(**B**, C)，码 = B，FD = {B→C}
- R₂：自动 3NF ✓

**3NF 最终结果**：

| 关系 | 属性 | 码 | FD |
|------|------|-----|-----|
| R₁₁ | A, D, B | AD | AD→B |
| R₁₂ | B, C | B | B→C |
| R₂ | A, D, E | ADE | — |

> ✅ 无损连接：R₁₁ ⋈ R₁₂ = R₁，R₁ ⋈ R₂ 恢复原关系
> ✅ 保持函数依赖：AD→B 和 B→C 分别保留

## 7. 模式分解

> 模式分解准则：无损连接（分解后再次自然连接，与分解前相同）、保持函数依赖

### 判断无损连接——表格法（Chase 法）

**步骤**：
1. 建表：行 = 每个分解后的子模式，列 = U 中所有属性
2. 填 aᵢ/bᵢⱼ：若属性属于该子模式填 aᵢ，否则填 bᵢⱼ
3. 用 F 中每条 FD 反复"追平"（左部相同 → 右部对齐，优先用 a）

**例**：U={A,B,C,D}，F={A→B, C→D}，ρ={AB, AC, CD}

| 初态 | A | B | C | D |
|------|---|---|---|---|
| AB | a₁ | a₂ | b₁₃ | b₁₄ |
| AC | a₁ | b₂₂ | a₃ | b₂₄ |
| CD | b₃₁ | b₃₂ | a₃ | a₄ |

用 A→B：A 列 a₁ 行对齐 → B 列 b₂₂ 改为 a₂
用 C→D：C 列 a₃ 行对齐 → D 列 b₁₄ 改为 a₄

结果 AB 行变 [a₁, a₂, b₁₃, a₄]。**有全 a 行 → 无损连接** ✅

### 分解为 3NF（保持依赖 + 无损连接）

1. 求 F 的最小函数依赖集 Fₘᵢₙ
2. 对 Fₘᵢₙ 中**左部相同**的依赖合并：X→Y₁, X→Y₂ ⇒ X→Y₁Y₂
3. 每个合并后的依赖 X→Y → 建一个关系模式 R(XY)，码为 X
4. 若没有子模式包含候选码 → 添加一个包含候选码的子模式
5. 去掉被包含的子模式
